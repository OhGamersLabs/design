## 分件结构 {#structure}

第 1 层在第 0 层机械本体外叠加贴身核心胸甲、护颈与腰胯重磅战术垂帘，奠定波斯武者式硬甲＋长布的轮廓层次。

- **强化胸甲与 OG 标识**：多层冷灰白斜切胸甲紧扣前胸，深炭灰高立领围绕颈部，白色闭合 OG 标识精准印于角色左胸斜上方（正面图位于画面右边）。
- **重磅战术前后垂帘**：哑光暖灰褐厚实织物垂帘自腰腹扣带自然垂落至膝盖上方，前后片底缘均嵌有深炭灰金属配重压条。
- **单侧腰胯挂载锁死**：仅角色左胯腰带挂载一只倒角哑光深灰矩形战术工具盒；角色右胯圆鼓保持素净空置，不设任何副刃或短鞘。
