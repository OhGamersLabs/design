第 0 层严格锚定已定稿的 [标准成年女素体](/standards/female-standard) 骨架、左右肩宽、四肢长度与精致瓜子脸轮廓，将颈下躯体构建为完整的硅碳仿生机械形态，确保第 1、第 2 层穿戴均在同一基线与同一比例下稳固叠穿。厘米身高未设定。

- **洁净瓷白面庞与全机械仿生耳**：额头洁净无宝石装饰，脸颊维持纯净瓷白肤色，仅沿双侧颧骨至下颌缘走一道纤细深灰单轨机械分模缝，并于上颧骨短斜段内嵌极细电青微光缝；双眸为独有电光紫水晶瞳并带锐利双白高光点；双侧均为紧凑黑曜石腔体、拉丝古金外环、发光电青传感内环与陶瓷白下颌铰链壳构成的 100% 全机械仿生耳。
- **不对称长发与挑染**：午夜蓝黑不对称碎刘海微微偏向角色右侧（正面图偏向画面左边），角色左额至太阳穴外沿带醒目电光蓝紫挑染条（正面图位于画面右边，角色左侧面尤为显著），长直发披垂至后背齐腰位置并夹带电光蓝紫内层发束。
- **颈下硅碳仿生躯体**：哑光黑曜石配拉丝古金肋甲躯干（肋侧点缀微小暖琥珀指示灯，背面嵌纵向发光电青脊椎灯列）、陶瓷白双臂与双腿配细古金分模线、肩肘髋膝踝五处发光电青圆盘伺服关节、黑曜石小腿护胫配古金纵条与箭矢护膝护踝，以及五指分明的黑金机械手与平底机械足。
