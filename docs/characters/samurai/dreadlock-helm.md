## 分件结构 {#structure}

第 3 层采用铁血赛博掠食者灵感打造的倒 V 压眉战盔与分段液压机械脏辫系统，立体贴合第 0 层颅顶而绝不穿模。

- **掠食者 V 形压眉战盔**：冷浅青灰棱面护额与护颊稳固箍紧第 0 层深钢蓝面罩，完整露出下半部面罩与双侧红色耳翼；双太阳穴装配圆形导管转轴毂，颅脊中轴覆有哑光深炭灰机械背骨。
- **角色右眉单侧高光锁**：仅在角色右眉棱斜切面嵌入一道浅亮黄微光细条（正面图位于画面左边），角色左眉棱保持纯冷青灰素面；无论正面或角色右侧面，主目镜始终保持烈焰猩红发光。
- **十至十二股液压机械脏辫**：哑光深炭黑波纹管脏辫导管每股均匀镶嵌二至三枚冷浅青灰金属箍环与暗金锁定细环，末端收于金属锥头，全束顺耳后沿高领向后自然垂落并止于上背部，稳固避开胸前 OG 标识、伸臂及披风下摆。
