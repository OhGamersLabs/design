# 身体比例固定基准

<span id="gray-proportion-review"></span>

::: info 当前参考与校准状态
当前以以下**原色、纤细的无装备身体三视**为参考。比例修订尚在校准，尺寸与穿戴资料暂不随之变更。

修订保留原肤色、银白发、蓝眼、黑色运动内搭与纤细体型，并核对正、侧、背三视的一致性。
:::

穿戴层应按已选基准校准；现有偏差待逐张同步。外套体积不等于身体加宽；鞋底厚度不改变赤脚身高。
