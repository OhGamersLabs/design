# 先建立稳定的身体基准

## 比例

前、侧、背图对应同一套肩、骨盆、膝和脚底位置。体型纤细且有运动感，不因镜头改变身体宽窄。

## 参考层

黑色运动基础层用于展示体型，不是最终服装里需要额外叠穿的一层。

## 站姿

正面拆解头部与躯干稳定，双脚承重均衡；角色卡可以有造型，但不能反向覆盖中性站姿规范。
