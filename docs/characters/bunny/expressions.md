# 当前身份表情与变化

## v2 · 16 格表情

银白短发、蓝眼、脸型与五官关系与[中性头部样板](/characters/bunny/face)保持一致。保持手绘线稿与赛璐璐色块，情绪变化由眉眼和嘴型共同承担；眼睛保持蓝色，不因惊讶、担忧或兴奋改变瞳色。

当前16格保留此前耳部与发色修订稿，身份、耳部连接、银白发色、线条密度与赛璐璐画风已逐格核对；原有16项情绪及排列保持。本轮更新中性头部卡与衣装、袜装正背面，未重新绘制表情板。当前基模尺寸另见[图面尺寸](/characters/bunny/dimensions)。
