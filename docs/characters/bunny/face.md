# 面部与身份

银白发、蓝色眼睛、发束结构与五官关系以本轮中性头部样板为依据。采用日系手绘线稿与清楚的赛璐璐色块。

## v2 · 中性头部样板

<ReleaseImage src="/characters/bunny/3.1.0/head-v2-cel-reference-v2.webp" original="/media/bunny/3.1.0/head-v2-cel-reference-v2.png" alt="v2中性头部样板：正面、角色右侧与背面，银白短发、蓝眼与清楚发束" caption="v2 · 中性头部样板" />

本轮重新绘制完整中性头部卡，双耳朝向后侧，正面露出收敛的耳廓，由鬓发自然遮住耳根；耳前发束保持银白色。三视统一手绘线稿与赛璐璐色块。

正面双眼朝向共同的视线目标，保留轻微自然差异，不把一只眼机械镜像到另一侧。侧面按转向收窄可见眼形，眉眼、鼻尖、嘴与下颏保持连贯关系。

发色以银白主面为主，少量冷灰蓝硬边阴影说明发束重叠。发旋、刘海、脸侧外翻束与后颈长度保持同一套分组，不用密集碎线或大面积蓝紫渐变塑造头发。

[16格表情](/characters/bunny/expressions)以这张中性样板统一耳部、发色与画风；[基模](/characters/bunny/body-base)、[首层衣装](/characters/bunny/innerwear)和[袜装](/characters/bunny/hosiery)各重新绘制一张完整正面，侧背沿用已确认稿。基模正面的[图面尺寸](/characters/bunny/dimensions)按对应新原图重新量读，头部装备仍保留既有资料。
