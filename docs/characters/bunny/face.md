# 面部与身份

银白发、蓝色眼睛、发束结构与五官关系以本轮中性头部样板为依据。采用日系手绘线稿与清楚的赛璐璐色块。

## v2 · 中性头部样板

<ReleaseImage src="/characters/bunny/3.1.0/head-v2-cel-reference-v3.webp" original="/media/bunny/3.1.0/head-v2-cel-reference-v3.png" alt="v2中性头部样板：正面、角色右侧与背面，银白短发、蓝眼与清楚发束" caption="v2 · 中性头部样板" />

本轮从空白画布重新绘制完整中性头部卡，保持双耳朝后、由鬓发自然遮住耳根的连接与银白发束设计，以清楚线稿、连续平涂与硬边阴影重新呈现。

正面双眼朝向共同的视线目标，保留轻微自然差异，不把一只眼机械镜像到另一侧。侧面按转向收窄可见眼形，眉眼、鼻尖、嘴与下颏保持连贯关系。

发色以银白主面为主，少量冷灰蓝硬边阴影说明发束重叠。发旋、刘海、脸侧外翻束与后颈长度保持同一套分组，不用密集碎线或大面积蓝紫渐变塑造头发。

[16格表情](/characters/bunny/expressions)保留此前已复核的身份与耳发稿。[首层衣装](/characters/bunny/innerwear)和[袜装](/characters/bunny/hosiery)本次各完整重绘正面与背面；[基模](/characters/bunny/body-base)及对应[图面尺寸](/characters/bunny/dimensions)保持原稿。当前头部装备见[累计穿戴与独立部件](/characters/bunny/headgear#headgear-wearing)。
