# 同一张脸的不同状态

## 身份基准

成年、纤细而有运动感的形象；蓝色眼睛与白发构成常态。面宽、眼距、鼻口位置和下颌形状在不同表情中保持稳定。

## 口部表演

深色护目镜弱化眼神时，嘴角、口形和头部方向承担更多情绪。需要清晰眼部表演的镜头可用摘镜状态，不临时把镜片改为透明。

## 状态边界

红眼只作为特殊状态的视觉参考。常态不同时改变眼色、脸型和头发结构。
