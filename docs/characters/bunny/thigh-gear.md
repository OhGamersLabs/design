# 双带把盒袋固定在外侧

## 位置

双带环绕人物右大腿，盒体与软袋分别绘制。正面图中位于画面左侧。

## 固定

两道带限制盒袋的旋转趋势，前、侧、后视图保持连续；扣具不随镜头移动到另一条腿。

## 动作

屈髋、蹲下和迈步时，检查盒袋与外套下摆的相互空间。图示不等于跑动时完全不滑移。
