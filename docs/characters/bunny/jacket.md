# 橙色外套

衣长、前后摆差与露腰空间统一按[服装尺寸规范](/characters/bunny/dimensions#garment-dimensions)核对，白色内搭保持固定衣长。

::: info 第六层 · 橙色短外套
当前外套层沿用[腿部装备层](/characters/bunny/thigh-gear)的完整穿着，加入前长后短的开襟橙色夹克。正、侧、背三张完整人物及独立结构、局部细节两张板均为整张新绘，保留原生 PNG、放大入口与下载。本页单独展示夹克款式，图中不含承载带；[承载带与固定点](/characters/bunny/harness)另展示白衣外、夹克内的累计穿戴与层次关系。[头部装备层](/characters/bunny/headgear#headgear-wearing)已有累计三视与部件图；武器衣层仍待同步。
:::

## 前长后短夹克三视 {#jacket-wearing}

前襟端略盖过白色内搭，后中衣摆更短、露出窄白边，侧摆从长前端连续斜切到短后端。白衣尺寸保持，前端与红裤腰之间保留露腰空间；中央敞口中可见的白衣不算下摆露边。[固定衣长与逐图测量](/characters/bunny/dimensions#garment-dimensions)分别列出设计值、可见读数和遮挡时的基准推算。

短款衣身接近白色上衣下缘，红色前贴边与窄黑包边沿开襟向下，橙色下摆保持独立。宽松长袖收进短黑色罗纹袖口，袖口位于既有腕部设备上方；衣料增加袖量，不改变身体与手臂姿态。

左上臂保留一个功能翻盖袋，袋身正面中央采用正式 OG 连环标志的纯白图形，四周保留清楚的橙色留白，标志不贴近袋盖、侧缝或袋底。袋盖和周围袖布保持橙色。右袖不复制口袋或 OG。领口改为随前襟断开的普通黑色短罗纹领，前开口自然延续，不再使用领前 OG 圆牌或闭合项圈；前襟不增加拉链，也不把红前贴边解释为整件红色内衬。

正面中角色左侧位于画面右侧，背面相反；右侧视图中近侧为无口袋的右袖，远侧左袋可自然被遮挡。此前右手纯黑全指手套、左手半指橙边与采集设备、右大腿双带和盒袋保持对应关系。

本轮三张人物以同视角基模核对发色、深色轮廓与赛璐璐分面，均从空白画布完整绘制。衣层按既定款式和[尺寸规范](/characters/bunny/dimensions#garment-dimensions)核对，结构与细节板沿用；原始 PNG 保留生图工具直接输出。

## 夹克独立三视与外部分解 {#jacket-construction}

<ReleaseImage src="/characters/bunny/3.1.0/jacket-v2-highlow-construction-v1.webp" original="/media/bunny/3.1.0/jacket-v2-highlow-construction-v1.png" alt="外套独立正侧背三视及六组外部衣片示意：短衣身、左右袖、前开口黑罗纹领与左右黑袖口，左袖功能袋袋身正面中央为正式OG连环品牌图形" caption="v2 · 外套独立三视与外部分解" />

独立三视说明前长后短的衣形；分解示意分别展示衣身、左右袖、前开口领与左右袖口六组外部部件。红前贴边和黑包边留在衣身，左功能袋留在左袖，纯白 OG 连环品牌图形位于袋身正面中央；领口不带 OG 圆牌。衣身的领口与袖窿、袖端与袖口按对应接合位置阅读，不额外复制领片、袖段或袖口。

这些是缝合关系的可见设计示意，不表示衣片是穿戴时可拆卸的模块，也不是生产纸样。

## 夹克局部细节 {#jacket-details}

<ReleaseImage src="/characters/bunny/3.1.0/jacket-v2-highlow-details-v1.webp" original="/media/bunny/3.1.0/jacket-v2-highlow-details-v1.png" alt="外套四组局部细节：普通前开口领正背、带正式OG连环品牌图形的左袖袋开合、黑袖口接缝与翻转、红前贴边和橙色下摆" caption="v2 · 外套局部细节" />

四组细节分别对照普通前开口领正背、左袋闭合与开启、袖口外侧与接缝翻转、红前贴边与下摆。左袋翻盖保留上方缝合连接，打开后露出袋口。纯白 OG 连环品牌图形位于袋身正面中央，袋盖开合时标志随袋身保持原位。不同状态用于说明同一部件，不计为新增部件。

两张板仅说明可见外部结构。隐藏固定方式、完整内衬、制造尺寸与真实活动范围尚未验证。
