# 蓬松外层包住紧实核心

## 轮廓

橙色短夹克保留宽松袖体，袖口收束；开放前襟让白色内搭和承载带仍可读。

## 归属

黑色高领属于外套系统，不与头具重复。肩带、袖袋与眼形标识各自有明确位置。

## 动作

衣褶解释布料在肘部和袖口的张力。袖口留出手套与腕具的连接，不用硬壳体积解释柔软衣袖。
