# 按覆盖关系由内向外组合

## 第一层

身体比例稳定后，加入白色内搭、红色短裤、袜套与前臂套，先确定覆盖边界。

## 第二层

加入承载带、腿侧盒袋和护膝，检查扣件落点、带路及左右侧别。

## 第三层

外套覆盖核心层，再加入手套、鞋、头具与背负工具。检查领口、袖口、腰部和背面遮挡。
