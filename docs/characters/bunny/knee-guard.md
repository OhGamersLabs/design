# 膝前硬片与膝后弹性带

## 形体

黑色护膝位于人物左膝，穿在橙袜外。上部红线与灰色铆钉保持简洁可读。

## 带路

红色固定带水平绕到膝后，后视图能读出带面，而不是仅像袜子的折痕。

## 活动

护片与上方服装保留间隔，不形成跨越膝关节的长刚板。屈膝需要袜面和带路容许变形。
