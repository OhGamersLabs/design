# 扩展姿态 不扩写角色

## 身份与侧别

面宽、眼距、鼻口和下颌保持稳定，常态蓝眼。用人物自身左右管理不对称装备；遮挡可以隐藏部件，不能改变安装位置。

## 结构与动作

关节保留活动空间，硬片、弹性带和织物分别解释变形。护膝红带、腿侧盒袋、背负鞘和外套下摆需要在动作中检查相互空间。

## 画法一致

轮廓清楚、平涂色块、有限硬边阴影。近景不增加写实毛丝和连续材质反射；局部精度增加不意味着更换渲染风格。

## 验证边界

图像设定不替代真实承重、公差、舒适性、工具安全和连续运动验证。
