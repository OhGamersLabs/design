# 应用规范

新图以固定人物基准为起点，分别核对身份、左右侧装备、覆盖关系与姿势。结构参考和表现图承担不同用途，不用一张姿势图反推全部尺寸。

## 身份与比例

<ul><li>以<a href="/characters/bunny/face">面部与身份</a>的银白发、蓝色眼睛、发束和五官位置为准；<a href="/characters/bunny/expressions">当前身份表情集</a>提供已按现行脸型、瞳色与发束校准的情绪变化；历史表情折叠保留供回溯。</li><li>正侧背结构图使用一致站位与比例。人物尺寸的 H 是可见发冠到赤脚地面，不含头部装备与鞋底；双匕首总长以当前正面基准 H0 定义：角色右侧墨黑为 0.36H0，左侧骨白为 0.42H0；细分按选定母版核对，人物投影另行记录。详见<a href="/characters/bunny/dimensions">人物统一尺寸</a>与<a href="/characters/bunny/dimensions#assassin-daggers-dimensions">双匕首设计目标</a>。</li><li>动作、透视与原稿同姿势表现可以改变屏幕上的投影长度，不能据此改动人物基准或把所有视角强行拉伸成同宽。</li></ul>

## 左右侧装备

所有左右都以角色自身为准，不随画面朝向交换。

<ul><li>角色左腿为橙色长袜，右腿为白色短袜；右大腿配置任务终端与维护盒袋。见<a href="/characters/bunny/hosiery">袜装</a>与<a href="/characters/bunny/thigh-gear">腿部装备</a>。</li><li>角色右手为全指手套与红色腕环，左手为露指手套与橙色腕部设备。见<a href="/characters/bunny/hands">手部装备</a>。</li><li>角色右侧固定墨黑獠牙匕首与深色宽刃鞘，左侧固定骨白匕首与浅色曲鞘。正背切换或镜像检查时，以部件实际归属侧复核，不直接沿用画面左、右位置。</li></ul>

## 衣层与遮挡

<ul><li>按<a href="/characters/bunny/assembly">衣层与部件阅读顺序</a>核对贴身衣、袜靴、局部装备、外套、裤腰皮带和护目镜。肩带、背部 H 带、胸下带和上衣至腰带连接均已取消。</li><li>黑色皮带穿过红裤裤袢；双刀采用无鞘后腰交叉方向，已有短托、束带与带耳的局部外观方案，人物三视补充角度与遮挡关系，动态避让仍需进一步验证。</li><li>护目镜保持露嘴轮廓；当前腿部不添加旧稿护膝。完整衣装见<a href="/characters/bunny/headgear#headgear-wearing">当前护目镜衣层</a>；异构双匕首使用新的尺寸母版，人物图分别展示两张独立双持姿势方案与后腰交叉携行三视。</li></ul>

## 武器与姿势用途

<ul><li>当前武器方向为刺客双匕首，以墨黑宽角獠牙与骨白前掠两种整体造型成对，采用后腰交叉携行方向，局部固定外观、两张供比较的独立双持姿势方案和携行三视已分别展示。左右手套、腰带与右腿装备按同一归属保持，动态间隙另行验证，旧大剑和双手棍资料保留为历史。</li><li>中性三视用于结构与覆盖核对，不等于原稿同姿势角色卡。手持或动作表现需要对应的握持、透视与衣物变形，不能把收纳图直接当作已完成的动作参考。</li><li><a href="/characters/bunny/weapon-history">旧版武器尺寸</a>仅作历史回溯，不用于校准当前双匕首。</li></ul>
