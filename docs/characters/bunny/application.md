# 使用检查 {.bunny-sr-only}
<span id="应用规范"></span>

人物图以固定人物基准为起点，分别核对身份、两侧装备归属、覆盖关系与姿势。结构参考和表现图承担不同用途，不用一张姿势图反推全部尺寸。

## 身份与比例

- 以[面部与身份](/characters/bunny/#identity)的银白发、蓝色眼睛、发束和五官位置为准；[身份表情集](/characters/bunny/#expressions)的情绪变化保持同一脸型、瞳色与发束。
- 正面、角色右侧面与背面结构图使用一致站位与比例。人物尺寸的 H 是可见发冠到赤脚地面，不含头部装备与鞋底；双匕首总长的设计目标以正面基准 H0 表示：角色右墨黑约为 0.225 H0，角色左骨白约为 0.263 H0。携行背面图读数约为墨黑 0.228 H0、骨白 0.259 H0；计入端点与配准容差的范围分别约为 0.219–0.237 H0、0.249–0.269 H0，两把总长设计目标均在对应范围内，见[携行背面图面核对](/characters/bunny/dimensions#dagger-figure-observations)；细分按母版核对，人物投影另行记录。详见[身体尺寸](/characters/bunny/dimensions#body-dimensions)与[双匕首设计目标](/characters/bunny/dimensions#weapon-dimensions)。
- 动作、透视与原稿同姿势表现可以改变屏幕上的投影长度，不能据此改动人物基准或把所有视角强行拉伸成同宽。

## 两侧装备归属 {#两侧装备归属}
<span id="左右侧装备"></span>

角色左与角色右都以角色自身为准，不随画面朝向交换。

- 角色左腿为橙色过膝袜，角色右腿为白色短袜；角色右大腿配置任务终端与维护包。见<a href="/characters/bunny/hosiery">袜装</a>与<a href="/characters/bunny/thigh-gear">腿带</a>。
- 角色右手为黑色全指手套与红色腕护环，角色左手为黑色半指手套与橙色腕部设备。见<a href="/characters/bunny/hands">手部</a>。
- 图面可见：双匕首不带鞘，挂在背后的裤腰皮带上，角色右侧为墨黑匕首，角色左侧为骨白匕首。后中裤袢两侧各有一片黑色皮挂片，每把握柄各绕一条带圆形银按扣的黑短带，红领可见，裸露刀身交叉。设计要求：刀身从正面穿过挂片窄口，到挂片后面贴着短裤，全部露在外面；护手卡在窄口，刀的重量压在护手上；取刀时先打开按扣，再沿握柄方向向外上方抽出。背面图中局部刀根被黑挂片遮挡，但没有可独立辨认的窄口轮廓，也未画出抽刀动作。正背切换或镜像检查时，以部件实际归属侧复核，不直接沿用画面左、画面右的位置。

## 衣层与遮挡

- 按[衣层与部件阅读顺序](/characters/bunny/#layers)核对贴身衣、袜靴、局部装备、橙色夹克、护目镜、裤腰皮带和双匕首。躯干只有一条黑色裤腰皮带。
- 黑色皮带穿过红裤裤袢；双刀挂在背后裤腰皮带处，图面可见黑色皮挂片和握柄按扣短带。设计要求为挂片上沿翻过皮带并在皮带下沿缝死，窄口与刀身垂直且长度等于刀身宽度，按扣带压住刀柄根部；取刀时先打开按扣，再沿握柄方向向外上方抽出。图中未画出可独立辨认的穿刀窄口、皮带下沿固定缝线与抽刀；人物三视说明角度与遮挡关系，动态避让未验证。
- 护目镜保持露嘴轮廓。完整衣装见[双匕首衣层](/characters/bunny/weapon#carry)；异构双匕首以尺寸母版为依据，人物图展示背后裤腰皮带挂片携行三视。

## 武器与姿势用途

- 刺客双匕首以墨黑獠牙刃与骨白弯刃成对；墨黑的银色内凹刃缘弯向钩尖，骨白的刀根较直、向前端弯曲并收成掠起的尖端，两把刀身均只有护手上方刀背侧的一条细红楔，采用背后裤腰皮带挂片携行，挂片与握柄短带的可见连接和遮挡关系由携行三视说明；窄口固定与抽刀为设计要求。角色左手与角色右手的手套、裤腰皮带与角色右腿装备保持各自归属，动态间隙未验证。
- 中性三视用于结构与覆盖核对，不等于原稿同姿势角色卡。手持或动作表现需要对应的握持、透视与衣物变形，不能把收纳图直接当作已完成的动作参考。

## 出图核对

1. 身份与身体比例是否匹配人物基准。
2. 角色左侧与角色右侧的部件归属是否正确，装备是否符合对应衣层。
3. 衣层遮挡、带路、固定点与武器收纳是否连续一致。
4. 线条、色块与材质是否符合[画风与配色](/characters/bunny/visual-language)，没有新增未经定义的花纹或结构。
5. 是否明确区分结构三视与姿势表现的用途；放大或高清输出不应自动新增设计细节。
