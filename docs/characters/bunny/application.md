# 应用规范

新图以固定人物基准为起点，分别核对身份、左右侧装备、覆盖关系与姿势。结构参考和表现图承担不同用途，不用一张姿势图反推全部尺寸。

## 身份与比例

<ul><li>以<a href="/characters/bunny/face">面部与身份</a>的银白发、蓝色眼睛、发束和五官位置为准；<a href="/characters/bunny/expressions">当前身份表情集</a>提供已按现行脸型、瞳色与发束校准的情绪变化；历史表情折叠保留供回溯。</li><li>正侧背结构图使用一致站位与比例。人物尺寸的 H 是可见发冠到赤脚地面，不含头部装备与鞋底；大剑总长按当前正面基准 H0 的 0.85 设定，单件概念尚未与人物合绘对位。详见<a href="/characters/bunny/dimensions">人物统一尺寸</a>与<a href="/characters/bunny/dimensions#obsidian-sword-dimensions">大剑概念尺寸</a>。</li><li>动作、透视与原稿同姿势表现可以改变屏幕上的投影长度，不能据此改动人物基准或把所有视角强行拉伸成同宽。</li></ul>

## 左右侧装备

所有左右都以角色自身为准，不随画面朝向交换。

<ul><li>角色左腿为橙色长袜，右腿为白色短袜；右大腿配置任务终端与维护盒袋。见<a href="/characters/bunny/hosiery">袜装</a>与<a href="/characters/bunny/thigh-gear">腿部装备</a>。</li><li>角色右手为全指手套与红色腕环，左手为露指手套与橙色腕部设备。见<a href="/characters/bunny/hands">手部装备</a>。</li><li>正背切换或镜像检查时，以部件实际归属侧复核，不直接沿用画面左、右位置。</li></ul>

## 衣层与遮挡

<ul><li>按<a href="/characters/bunny/assembly">衣层与部件阅读顺序</a>核对贴身衣、袜靴、局部装备、外套、内穿承载系统和护目镜。承载带本体图隐去外套，只用于看清带路，不代表实际少穿一层。</li><li>承载带位于白色内搭外、橙色夹克内；固定点、扣件和后腰收纳件应保持连接关系，不能为了展示单件而任意移位。</li><li>护目镜保持露嘴轮廓；当前腿部不添加旧稿护膝。完整衣装见<a href="/characters/bunny/headgear#headgear-wearing">当前护目镜衣层</a>；大剑握持与背负尚待绘制。</li></ul>

## 武器与姿势用途

<ul><li>当前武器方向为黑曜石感大剑，现有单件加厚正侧与断口细节概念板。后续人物图仍需分别核对握持、背负、左右装备与覆盖关系；此前双手棍人物图保留为历史。</li><li>中性三视用于结构与覆盖核对，不等于原稿同姿势角色卡。手持或动作表现需要对应的握持、透视与衣物变形，不能把收纳图直接当作已完成的动作参考。</li><li><a href="/characters/bunny/weapon-history">旧版武器尺寸</a>仅作历史回溯，不用于校准当前大剑。</li></ul>

## 出图核对

<ol><li>身份与身体比例是否仍匹配当前基准。</li><li>左右侧部件是否正确，是否误加旧版装备。</li><li>衣层遮挡、带路、固定点与武器收纳是否连续一致。</li><li>线条、色块与材质是否符合<a href="/characters/bunny/visual-language">配色与画法</a>，没有新增未经定义的花纹或结构。</li><li>是否明确区分结构三视、姿势表现与历史参考；放大或高清输出不应自动新增设计细节。</li></ol>
