# 使用检查 {.bunny-sr-only}
<span id="应用规范"></span>

新图以固定人物基准为起点，分别核对身份、两侧装备归属、覆盖关系与姿势。结构参考和表现图承担不同用途，不用一张姿势图反推全部尺寸。

## 身份与比例

- 以[面部与身份](/characters/bunny/#identity)的银白发、蓝色眼睛、发束和五官位置为准；[身份表情集](/characters/bunny/#expressions)的情绪变化保持同一脸型、瞳色与发束。
- 正面、角色右侧面与背面结构图使用一致站位与比例。人物尺寸的 H 是可见发冠到赤脚地面，不含头部装备与鞋底；双匕首总长以正面基准 H0 定义：角色右墨黑为 0.36 H0，角色左骨白为 0.42 H0；细分按母版核对，人物投影另行记录。详见[身体尺寸](/characters/bunny/dimensions#body-dimensions)与[双匕首设计目标](/characters/bunny/dimensions#weapon-dimensions)。
- 动作、透视与原稿同姿势表现可以改变屏幕上的投影长度，不能据此改动人物基准或把所有视角强行拉伸成同宽。

## 两侧装备归属 {#两侧装备归属}
<span id="左右侧装备"></span>

角色左与角色右都以角色自身为准，不随画面朝向交换。

- 角色左腿为橙色过膝袜，角色右腿为白色短袜；角色右大腿配置任务终端与维护包。见<a href="/characters/bunny/hosiery">袜装</a>与<a href="/characters/bunny/thigh-gear">腿带</a>。
- 角色右手为黑色全指手套与红色腕护环，角色左手为黑色半指手套与橙色腕部设备。见<a href="/characters/bunny/hands">手部</a>。
- 双匕首在后腰交叉携行，角色右侧为墨黑匕首，角色左侧为骨白匕首；刀身大部分外露，由刀根短托和柄根束带固定在裤腰皮带上。正背切换或镜像检查时，以部件实际归属侧复核，不直接沿用画面左、画面右的位置。

## 衣层与遮挡

- 按[衣层与部件阅读顺序](/characters/bunny/#layers)核对贴身衣、袜靴、局部装备、橙色夹克、裤腰皮带和护目镜。躯干只有一条黑色裤腰皮带。
- 黑色皮带穿过红裤裤袢；双刀在后腰交叉携行，局部固定由短托、束带与带耳组成，人物三视说明角度与遮挡关系，动态避让未验证。
- 护目镜保持露嘴轮廓。完整衣装见[护目镜衣层](/characters/bunny/headgear#headgear-wearing)；异构双匕首以尺寸母版为依据，人物图展示后腰交叉携行三视。

## 武器与姿势用途

- 刺客双匕首以墨黑宽角獠牙与骨白前掠两种整体造型成对，采用后腰交叉携行，局部固定结构与携行三视说明连接和遮挡关系。角色左手与角色右手的手套、裤腰皮带与角色右腿装备保持各自归属，动态间隙未验证。
- 中性三视用于结构与覆盖核对，不等于原稿同姿势角色卡。手持或动作表现需要对应的握持、透视与衣物变形，不能把收纳图直接当作已完成的动作参考。

## 出图核对

1. 身份与身体比例是否匹配人物基准。
2. 角色左侧与角色右侧的部件归属是否正确，装备是否符合对应衣层。
3. 衣层遮挡、带路、固定点与武器收纳是否连续一致。
4. 线条、色块与材质是否符合[画风与配色](/characters/bunny/visual-language)，没有新增未经定义的花纹或结构。
5. 是否明确区分结构三视与姿势表现的用途；放大或高清输出不应自动新增设计细节。
