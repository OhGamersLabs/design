# 鞋靴

::: info 鞋靴层 · 红白鞋靴
当前鞋靴层沿用[白色上衣、红色短裤](/characters/bunny/innerwear)与[非对称袜装](/characters/bunny/hosiery)，加入红白鞋靴。正、侧、背三张完整人物与独立结构板均为整张新绘，分别保留原生 PNG、放大入口与下载。下一层[手部装备](/characters/bunny/hands)现有完整穿着三视及两张部件板；[腿部装备](/characters/bunny/thigh-gear)也有穿着三视及两张部件板，[外套层](/characters/bunny/jacket)现有穿着三视与两张部件板，外侧承载带及之后的衣层尚未同步。
:::

## 鞋靴穿着三视 {#footwear-wearing}

角色左腿为橙色长袜，右腿为白色短袜；正面中橙袜在画面右侧，背面相反。右侧视图朝画面右侧，远侧橙袜腿及鞋自然遮挡在近侧之后。袜筒连续进入鞋口，白色鞋带结与短尾收在上鞋舌袋内。

三张完整人物各为 1024×1536。鞋底厚度属于鞋层外形，人物比例仍参照[当前基模与图面尺寸](/characters/bunny/dimensions)；本页不提供隐藏踝位置、内部足床的精确尺寸或三维装配结论。

独立结构板沿用已确认的双色硬边圆锚设计。

本轮三张人物以同视角基模核对发色、深色轮廓与赛璐璐分面，均从空白画布完整绘制。衣层按既定款式和[尺寸规范](/characters/bunny/dimensions#garment-dimensions)核对，结构与细节板沿用；原始 PNG 保留生图工具直接输出。

## 鞋靴独立结构 {#footwear-construction}

<ReleaseImage src="/characters/bunny/3.1.0/footwear-v2-layer3-construction-v2.webp" original="/media/bunny/3.1.0/footwear-v2-layer3-construction-v2.png" alt="红白鞋靴独立结构：右鞋各面、鞋底、部件分层与鞋带收纳，灰色圆锚双色硬边" caption="v2 · 鞋靴独立结构 · 金属硬边色块修订 · 1536×1024" />

01—04 展示同一只右鞋的正面、外侧、内侧和背面，05 为鞋底。外踝大圆件与前端小橙圈属于外侧，内侧没有这两件；正面与背面只见大圆件侧缘，前端小橙圈不出现在后跟面。

06 分开鞋帮、白色中底与带红色侧块的黑色外底，虚线表示相互对应的位置。07 对照上鞋舌袋打开与合拢：白色鞋带结和短尾收在袋中，下方仍保留交叉系带。结构板用于说明可见部件与接合位置，不是裁剪纸样、制造步骤或投产规格。
