# 同款镜像鞋，前侧后分工明确

## 正面

三槽鞋舌板、白色交叉带、鞋头四铆钉与外角橙圈组成主要识别。

## 左右对应

左右鞋是同款镜像，鞋底高度一致。前鞋舌不能从背面鞋口长出，侧扣不变成随机装饰。

## 侧面

踝扣、白色中底与红色鞋跟分层，外后跟保留金色六角标。外侧标记不移动到正后跟。
