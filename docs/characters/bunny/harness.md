穿着三视显示身体至裤腰皮带的第 0 到 8 层，包含护目镜。躯干只有一条黑色皮带，穿过红裤裤袢围绕裤腰一圈。

衣层编号不等于实际穿衣顺序：上身由内到外是白色内搭 → 橙色夹克；皮带只围绕红裤裤腰。

| 图中标记 | 中文说明 |
| --- | --- |
| 01 BELT | 皮带整件：一圈黑色皮带、矩形针扣和一个收尾环。 |
| 02 BUCKLE FRONT | 扣件正面：带尾穿过扣框和收尾环，短扣针端与带孔配合。 |
| 03 BUCKLE SIDE | 扣件侧剖：展示带体折返与叠层；OUT 为外侧，BODY 为贴身侧。 |
| 04 FRONT | 正面穿戴：扣件位于裤腰前中，带尾和收尾环在画面右侧。 |
| 05 BACK | 背面穿戴：皮带从后中和两侧后方的红色裤袢下穿过，后袋口可见。 |
| 06 RIGHT SIDE | 角色右侧面：皮带随裤腰向前下倾，前端可见扣件侧缘。 |
| 07 DIMENSIONS | 板面印字标注与俯视位置：belt w（带宽）= 0.0125 H0；buckle（扣件）= 1.5 w × 1.25 w，w 为带宽。0 为前中扣位，五个裤袢标为 30、110、180、250、330；R / L 分别为角色右 / 角色左。 |

这张板只展示皮带、扣件、收尾环及它们穿过裤袢的关系。第 9 层双匕首的黑色皮挂片不在本板内，见[双匕首挂片挂法](/characters/bunny/weapon#dagger-waist-mount-structure)。板上的 H0 是身体发冠至赤脚地面的设计单位，所列比例为板面印字标注，未登记为设计目标。穿着图带宽约 0.016 H0（含描线），印字 0.0125 H0，待复核。

皮带与扣件说明外观和连接位置，不能据此推断制造尺寸或动态间隙。身体、白衣、红裤和夹克的尺寸分别参照[身体尺寸](/characters/bunny/dimensions#body-dimensions)与[服装尺寸](/characters/bunny/dimensions#garment-dimensions)。
