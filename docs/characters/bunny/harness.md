# 带路连续，扣件有落点

## 带路

上躯干带、腰带与腿侧附挂使用不同路线。每条带在转到背面后仍有连续去向。

## 扣件

橙色圆扣、矩形调节件与折返带端使用有限而一致的造型语言；扣件固定在带面或支撑结构上。

## 承载

装备的视觉承载关系应回到躯干或骨盆区域，不仅悬挂在松软外套上。真实承重与抗滑表现需另外验证。
