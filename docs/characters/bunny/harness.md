衣层编号不等于实际穿衣顺序：上身由内到外是白色内搭 → 橙色夹克；皮带只围绕红裤裤腰。

| 图中标记 | 中文说明 |
| --- | --- |
| BELT | 一圈黑色皮带与收尾环。 |
| BUCKLE | 腰前黑色扣件。 |
| LOOPS | 皮带穿过红裤裤袢，后袋口保持可见。 |
| DIRECT MOUNT | 直接装在皮带上的空槽挂夹；画面右侧是另一视角，不是增加一个部件。 |

双匕首在后腰交叉携行，刀身大部分露出。护手下短托、回绕柄根束带和穿腰带带耳的局部外观，以及刀体与挂点避开后裤袋口和角色右腿装备的关系，见[持握与后腰交叉携行](/characters/bunny/weapon#carry)。

皮带与挂点说明外观和连接位置，不能据此推断制造尺寸或动态间隙。身体、白衣、红裤和夹克的尺寸分别参照[身体尺寸](/characters/bunny/dimensions#body-dimensions)与[服装尺寸](/characters/bunny/dimensions#garment-dimensions)。
