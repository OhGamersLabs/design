# 承载带与固定点

肩带与腰带位于外套外侧。金色调节扣只在前肩，胸下带正面使用银色扣；背部黑色锚袢与银色挂扣连接腰带。橙色护盖位于前腰锚点，不复制到背面。

本页保留此前承载带设计，尚未同步[当前外套层](/characters/bunny/jacket)。旧22用于回溯外套外侧的承载位置，旧18隐去外套以露出带路，不能视为当前身体与衣层的累计结果；当前外套层不含承载带。
