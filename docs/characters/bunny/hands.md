# 双手与腕部装备

一侧是完整手套，另一侧为露指手套与腕部装备，不能自动镜像成两只相同的手。

手背、掌面和握持状态分别检查。硬片避开主要指关节，掌面保留握持所需的柔性。

金色指环状装饰与黑色手套分层，不能生成额外指头或把相邻手指粘成一块。

握电锯时还要在总成图检查手腕方向和手柄接触。

## 左右规则

人物右手为全指手套；左手为露指手套与腕具。手背、掌面、关节活动范围和握持接触要在完整角色动作中一起检查。
