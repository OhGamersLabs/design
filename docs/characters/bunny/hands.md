# 先能握持，再安排硬件

## 侧别

人物右手使用全指手套；左手使用露指手套与腕具。不能把两只手自动镜像成同款。

## 活动

硬片避开主要指关节，掌面保留握持所需的柔性。手背、掌面和握持状态分别检查。

## 细节

金色指环状装饰与手套分层，不粘连相邻手指。握持工具时同时检查手腕方向和手柄接触。
