# 上装与分层

## 内搭与短裤

<ReleaseImage
  src="/characters/bunny/1.0.0/innerwear.webp"
  alt="内搭与短裤"
  original="/media/bunny/1.0.0/innerwear.png"
  caption="内搭与短裤"
/>

白色高领短上衣保留小型横向开口，后片使用简洁的后中结构。

红色短裤采用明确裤腰与完整裤片，以平角裤脚收束。

布料使用低对比平涂和少量折线，不渲染成塑料或油亮皮革。

拆解表现前、侧、后片，重点是版型对应，而不是增加装饰性缝线。

## 外套与领口细节

<ReleaseImage
  src="/characters/bunny/1.0.0/jacket.webp"
  alt="外套与领口"
  original="/media/bunny/1.0.0/jacket.png"
  caption="外套与领口"
/>

主要结构是橙色短夹克、黑色立领、宽袖与收束袖口。

袖袋和眼形标识、肩部带件、拉链边与袖口各自保持清楚轮廓。

图中大体积来自布料蓬松，运动时应通过衣褶和袖口变形吸收位移。

视觉细节不能替代纸样；如需实物服装，仍需重新确定余量、开合位置和版型尺寸。

## 腰带与承载绑带

<ReleaseImage
  src="/characters/bunny/1.0.0/harness.webp"
  alt="腰带与承载绑带"
  original="/media/bunny/1.0.0/harness.png"
  caption="腰带与承载绑带"
/>

上躯干带、腰部带和腿部附挂各有独立路线。扣件应固定在带面上，而不是悬空。

橙色圆扣、矩形调节件与折返带端是有限的视觉语言，重复出现时形状要一致。

连接分析：需要承重的物体应通过带路回到躯干或骨盆，不能仅挂在松软外套布料上。

真实承重值和抗滑移表现仍未定义。
