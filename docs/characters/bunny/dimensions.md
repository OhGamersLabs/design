## 身体尺寸 {#body-dimensions}
<span id="current-body-measurements"></span>

资料为二维投影，不作为衣物成品尺寸或穿鞋后身体总高。

::: info 图面比例与实际设定
**H** 是可见发冠最高点至赤脚地面的图面高度；**h** 是可见发冠至下颏的头高，包含发量，不另估被头发遮住的颅顶。头身比为 H ÷ h。

记录的是原图像素与占 H 的比例，**厘米身高未设定**。肩、腰、胯和胸部宽度是指定水平线上的可见投影，不是骨骼尺寸或胸腰臀围。正面衣物胸宽取基础文胸杯外缘的指定截面，不计外侧腋前肤线，也不是最大裸胸宽或杯码。图面躯干段与腿长的起止点见各项定义。
:::

选择视角查看同一张原图上的标尺与读数。表中的“—”表示遮挡或无法可靠取点，未用其他视角补值。近似取点的容差只表示线宽与选点范围，不代表统计精度。

## 服装尺寸 {#garment-dimensions}

白色内搭与红色短裤以当前第一层图面读数为参照。夹克采用**前长后短**：前襟略盖白衣，后中露出窄白边，侧摆连续斜切。先看设计目标，再用下方标尺核对各图的实际偏差。

第一层图面读数用于比较衣层位置，不设合格区间。

夹克图中白衣下摆与前襟尖均可见，D 直接在同图读取：正面画面左／画面右约 0.192／0.190 h0，角色右侧面约 0.266 h0，均高于前端设计目标 0.04–0.10 h0；正面腰间留白 J2 约 0.253 h0，低于 ≥0.30 h0 的设计目标，均待复核。后中 D 的设计目标为 −0.09 至 −0.03 h0。

x1175 处第一层白衣下摆为 y1090；第 2–9 层比它高 24–37 px（约 0.05–0.08 h0）。第一层读数是参考，不保证后续衣层保持同一位置。

## 武器尺寸 {#weapon-dimensions}
<span id="assassin-daggers-dimensions"></span>

图面估读 **H0=3097 px**，对应正面身体图的可见发冠至赤脚地面（y=106→3203）；同图头高 **h0=470 px**。H0 是统一设计单位，不含护目镜和鞋底，厘米身高未设定。

整长设计目标为角色右侧墨黑匕首 **0.36H0**、角色左侧骨白匕首 **0.42H0**。整长主要落在刀刃，握柄与柄尾分别控制，手部连接不随整长等比缩放。

| --- | --- | --- |
| 整件总长（设计目标） | 0.360H0 | 0.420H0 |
| 刃部轴向段 | 约 0.239H0 | 约 0.301H0 |
| 护手中央段 | 约 0.013H0 | 约 0.013H0 |
| 红领段 | 约 0.007H0 | 约 0.007H0 |
| 可见握柄段 | 约 0.064H0 | 约 0.065H0 |
| 柄尾轴向段 | 约 0.037H0 | 约 0.034H0 |
| 刀身最大正面截宽 | 约 0.075H0 | 约 0.055H0 |
| 护手横向总宽 | 约 0.070H0 | 约 0.075H0 |
| 握柄最大正面截宽 | 约 0.027H0 | 约 0.029H0 |
| 刀身侧厚 / 握柄侧深 | 未测 | 未测 |

细分比例来自[并列正面母版](/characters/bunny/weapon#design)。图面整长约为墨黑 789 px、骨白 916 px；这些是 1536×1024 尺寸母版的原生像素，不是 H0 = 3097 px 的人物图像素。黑白比约 0.861，与 6:7 的设计目标相差约 0.5%。表内细分分别按每把总长设计目标换算，并记录原图像素与取点；这不是人物身高的另一次测量。

总长取刀尖至柄尾端点的直线距，各接缝向同一长轴投影。刀身与握柄宽度取垂直长轴的同一截面，护手横向总宽另计翼形外伸范围。“可见握柄段”描述图面分区，不等同于已验证的功能握长。

端点估读约 ±2 px、接缝约 ±4 px；段长约 ±8 px、截宽约 ±3 px。正面母版没有窄侧视，侧厚与握柄侧深保持未测。外观尺寸以正面母版为准。

后续母版、拆解与人物图按本表尺寸分别核对，实际源点、误差和遮挡状态记录在数据文件中，不用板面印字数字替代测量。

### 携行背面图面核对 {#dagger-figure-observations}

[携行背面原图](/media/bunny/daggers-back-latest.png)的原生画布为 2352×3520。两把刀的柄尾和刀尖均可见；骨白刀身在交叉处覆盖墨黑刀身。墨黑柄尾朝画面右上，骨白柄尾朝画面左上，28° 是握柄方向的设计目标。

下表为这张背面图的**图面估读**。整刀轴沿可见刀尖至柄尾的直线；局部刀身轴由两处可见刀身竖截面的中点连成，避免补画被护手遮住的刀根。弯刃没有唯一可证的全段直中轴。整刀端点弦的 23.76°／26.12° 不等同于 28° 的握柄方向设计目标；柄方向另从柄尾橙标中心至红领中心读取。

| 背面图面读数 | 角色右 · 墨黑 | 角色左 · 骨白 |
| --- | --- | --- |
| 柄尾 → 刀尖，原生 (x, y) | (1481, 1209) → (838, 1492) | (843, 1201) → (1563, 1554) |
| 整刀端点弦长 | 702.5 px | 801.9 px |
| 占同图 H0 代理（配准敏感性约 ±2%） | 0.23 H0 | 0.26 H0 |
| 整刀端点弦相对水平的锐角 | 23.76° | 26.12° |
| 柄方向：柄尾橙标中心 → 红领中心 | (1449, 1228) → (1288, 1312) | (882, 1221) → (1051, 1312) |
| 柄方向相对水平的锐角 | 约 27.6° | 约 28.3° |
| 柄方向取点范围对应角度 | 25.0°–30.1° | 25.9°–30.8° |
| 局部可见刀身轴相对水平的锐角 | 19.54° | 23.99° |
| 局部刀身轴取点范围对应角度 | 16.44°–22.54° | 22.54°–25.41° |

墨黑局部刀身轴取 (900, 1472.5) → (1000, 1437)，骨白取 (1200, 1388.5) → (1400, 1477.5)；各截面轮廓端点约 ±3 px。整刀端点各约 ±4 px；对应整刀轴角范围分别为 22.90°–24.62°、25.36°–26.89°。

柄方向两端中心各约 ±3 px，表中范围由端点容差框角点枚举得到；28° 设计目标落在两把柄方向的图面估读范围内，仍不表示三维角度验收。

以同视角身体背面图的可见发冠、后发尖和膝部阴影尖点配准，统一尺度约为 1.003，残差 RMS 约 1.81 px，得到本图 H0 代理约 3105.7 px；取点容差角点枚举给出的敏感范围为 3033.9–3177.4 px，不是统计置信区间。两把整刀图面弦长比约 0.876；这些二维投影值与 0.36 H0／0.42 H0、6:7 的设计目标分列，携行图读数短于设计目标，待复核。

图面可见：后中红色裤袢两侧的黑挂片互为镜像；画面左的骨白挂片扣带斜向画面左下绕过握柄，画面右的墨黑挂片扣带斜向画面右下绕过握柄，每条扣带有一颗银色圆扣。设计要求：挂片上沿翻过皮带，在皮带下沿缝死；刀身从正面穿过窄口，到挂片后面贴着短裤，全部露在外面；护手卡在窄口承重；取刀时先打开按扣，再沿握柄方向向外上方抽出。图中未画出刀身穿过挂片的窄口、皮带下沿缝线和抽刀；静态图不能验证隐藏固定路径、承载或抽刀间隙。

正面里墨黑柄尾从角色右腰后露出（画面左），骨白柄尾从角色左腰后露出（画面右），两刀尖在短裤两侧露出。T 姿角色右侧面看见墨黑柄尾，角色左侧面看见骨白柄尾。人物图说明携行的可见关系，不以姿势投影替代母版尺寸。

角色右侧面里，袖后露出近侧墨黑匕首的部分黑握柄、红领和黑色护手区域；腰后可见短墨黑刃段与较长骨白刃段重叠。柄尾与上部握柄被袖子遮住，黑挂片、按扣短带和护手相互叠合，完整边界及圆形按扣无法可靠分辨；不据此补齐整刀长度或侧厚。
