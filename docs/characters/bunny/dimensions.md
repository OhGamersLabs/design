## 身体尺寸 {#body-dimensions}
<span id="current-body-measurements"></span>

资料为二维投影，不作为衣物成品尺寸或穿鞋后身体总高。

::: info 图面比例与实际设定
**H** 是可见发冠最高点至赤脚地面的图面高度；**h** 是可见发冠至下颏的头高，包含发量，不另估被头发遮住的颅顶。头身比为 H ÷ h。

记录的是原图像素与占 H 的比例，**厘米身高未设定**。肩、腰、胯和胸部宽度是指定水平线上的可见投影，不是骨骼尺寸或胸腰臀围。正面衣物胸宽取基础文胸杯外缘的指定截面，不计外侧腋前肤线，也不是最大裸胸宽或杯码。图面躯干段与腿长的起止点见各项定义。
:::

选择视角查看同一张原图上的标尺与读数。表中的“—”表示遮挡或无法可靠取点，未用其他视角补值。近似取点的容差只表示线宽与选点范围，不代表统计精度。

## 服装尺寸 {#garment-dimensions}

白色内搭与红色短裤以当前第一层图面读数为参照。夹克采用**前长后短**：前襟略盖白衣，后中露出窄白边，侧摆连续斜切。先看设计目标，再用下方标尺核对各图的实际偏差。

第一层图面读数用于比较衣层位置，不设合格区间。

夹克图中白衣下摆与前襟尖均可见，D 直接在同图读取：正面画面左／画面右约 0.192／0.190 h0，角色右侧面约 0.266 h0，均高于前端设计目标 0.04–0.10 h0；正面腰间留白 J2 约 0.253 h0，低于 ≥0.30 h0 的设计目标，均待复核。后中 D 的设计目标为 −0.09 至 −0.03 h0。

x1175 处第一层白衣下摆为 y1090；第 2–9 层比它高 24–37 px（约 0.05–0.08 h0）。第一层读数是参考，不保证后续衣层保持同一位置。

## 武器尺寸 {#weapon-dimensions}
<span id="assassin-daggers-dimensions"></span>

图面估读 **H0=3097 px**，对应正面身体图的可见发冠至赤脚地面（y=106→3203）；同图头高 **h0=470 px**。H0 是统一设计单位，不含护目镜和鞋底，厘米身高未设定。

整长设计目标为角色右侧墨黑匕首约 **0.225 H0**、角色左侧骨白匕首约 **0.263 H0**。各段长度与正面宽度按并列正面母版的比例分别换算。

| --- | --- | --- |
| 整件总长（设计目标） | 0.225 H0 | 0.263 H0 |
| 刃部轴向段 | 约 0.149 H0 | 约 0.189 H0 |
| 护手中央段 | 约 0.008 H0 | 约 0.008 H0 |
| 红领段 | 约 0.005 H0 | 约 0.004 H0 |
| 可见握柄段 | 约 0.040 H0 | 约 0.041 H0 |
| 柄尾轴向段 | 约 0.023 H0 | 约 0.021 H0 |
| 刀身最大正面截宽 | 约 0.047 H0 | 约 0.035 H0 |
| 护手横向总宽 | 约 0.044 H0 | 约 0.047 H0 |
| 握柄最大正面截宽 | 约 0.017 H0 | 约 0.018 H0 |
| 刀身侧厚 / 握柄侧深 | 未测 | 未测 |

细分比例来自[并列正面母版](/characters/bunny/weapon#design)。图面整长约为墨黑 789 px、骨白 916 px；这些是 1536×1024 尺寸母版的原生像素，不是 H0 = 3097 px 的人物图像素。母版黑白整长比约 0.861；两把总长设计目标的比值约 0.853。表内细分分别按每把总长设计目标换算，并记录原图像素与取点；这不是人物身高的另一次测量。

总长取刀尖至柄尾端点的直线距，各接缝向同一长轴投影。刀身与握柄宽度取垂直长轴的同一截面，护手横向总宽另计翼形外伸范围。“可见握柄段”描述图面分区，不等同于已验证的功能握长。

端点估读约 ±2 px、接缝约 ±4 px；段长约 ±8 px、截宽约 ±3 px。正面母版没有窄侧视，侧厚与握柄侧深保持未测。外观尺寸以正面母版为准。

母版、拆解与人物图按本表尺寸分别核对，实际源点、误差和遮挡状态记录在数据文件中，不用板面印字数字替代测量。

### 携行背面图面核对 {#dagger-figure-observations}

[携行背面原图](/media/bunny/daggers-back-latest.png)的原生画布为 2352×3520。两把刀的柄尾和刀尖均可见；骨白刀身在交叉处覆盖墨黑刀身。墨黑柄尾朝画面右上，骨白柄尾朝画面左上。**28° 设计目标取刀尖至柄尾端点连线相对水平的角度**，握柄方向另读且更陡。

下表为这张背面图的**图面估读**。整刀轴沿可见刀尖至柄尾的直线；局部刀身轴由两处可见刀身竖截面的中点连成。弯刃没有唯一可证的全段直中轴，遮挡刀根不补值。握柄方向从柄尾橙标中心至红领中心读取，是观察值，不是另一项设计角度。

| 柄尾 → 刀尖，原生 (x, y) | (1474, 1193) → (845, 1512) | (850, 1171) → (1552, 1559) |

整刀端点各坐标约 ±4 px，弦长范围分别为 694.5–716.0 px、791.2–813.0 px；合并范围同时计入身体配准敏感性，H0 区间下界向下、上界向上取三位小数。两把总长设计目标均在对应范围内。弦角相对 28° 分别偏低约 1.11°、偏高约 0.93°；28° 不在仅由端点容差得到的角度范围内，不据此宣称角度严格吻合。

墨黑局部刀身轴取 (930, 1502) → (1040, 1469.5)，骨白取 (1270, 1409.5) → (1420, 1480.5)；各竖截面的可见轮廓 y 坐标约 ±3 px。柄方向两端中心各坐标约 ±3 px，表中范围由容差框角点枚举得到。两条整刀弦的锐交叉角约 55.82°，端点容差范围为 54.18°–57.48°；它不等于局部刀刃夹角或三维角度。

统一尺度约 1.00074，平移约 (−3.57, −2.05) px；三点残差分别约 4.03、5.66、2.78 px，RMS 约 4.32 px。同图 H0 代理约 3099.3 px，取点容差角点枚举的敏感范围为 3027.6–3170.9 px（约 ±2.3%），不是统计置信区间。两把整刀图面弦长比约 0.879；图面投影读数与各自总长设计目标分别记录。

图面可见：后中红色裤袢两侧各有黑挂片，顶边约与黑皮带上沿齐平、局部略高。画面左侧骨白挂片的可见区域约为 (1002, 1228)–(1108, 1321)，画面右侧墨黑挂片约为 (1232, 1229)–(1335, 1324)，可见轮廓约 ±4 px；这些是被刀与护手遮挡后的区域，不是完整挂片尺寸。两颗银色圆扣中心约为骨白 (1010, 1267)、墨黑 (1314, 1279)，各约 ±3 px。骨白扣带从银扣斜向画面左下，墨黑扣带从银扣斜向画面右下，均跨过红领上方的握柄。

黑挂片与刀根、护手相叠，局部刀根被黑挂片遮挡；图中没有可独立辨认、与刀身垂直的窄口轮廓。可见遮挡不能证明完整穿入路径或窄口尺寸。设计要求：挂片上沿翻过皮带，在皮带下沿缝死；刀身从正面穿过窄口，到挂片后面贴着短裤，全部露在外面；护手卡在窄口承重；按扣带压住刀柄根部；取刀时先打开按扣，再沿握柄方向向外上方抽出。皮带下沿固定缝线与抽刀动作未画出，静态图不验证承载或抽刀间隙。

正面里两处柄尾从腰侧露出：墨黑柄尾在角色右腰后（画面左），骨白柄尾在角色左腰后（画面右）；画面左侧胯旁还可见骨白刀尖。T 姿正面同样露出两处柄尾与画面左侧骨白刀尖；背面可见裸刃、挂片和按扣带，骨白在外浅 X 交叉。T 姿角色右侧面可见墨黑柄尾橙标、黑握柄与固定带；角色左侧面可见骨白柄尾橙标、黑白握柄、固定带与红领，两侧下方均露出叠合的窄刃投影。正面、侧面与 T 姿各视图均不用于推断整刀长度。

角色右侧面里，袖子后缘后方露出黑色柄部块面、红领与一颗银色圆扣，上方可见骨白柄尾尖及橙标。柄部下方沿臀后露出一段浅色窄刃投影。袖子和柄部相互遮挡，挂片与扣带的完整边界无法可靠分辨；不据此补齐整刀长度或侧厚。
