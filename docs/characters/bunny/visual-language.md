# 色彩负责识别 笔触统一材质

## 色彩分工

橙色用于外套、长袜和连接件；红色形成短裤与鞋的次级重心；白色建立轻亮轮廓；深灰黑组织护具和带路；淡紫灰解释白色阴影。

## 材质表达

头发按大束分组，白色本体配浅紫硬边阴影；织物用蓬松轮廓与折线表现张力；硬件用有限边缘高光表现硬度。材质不同，但都不采用连续写实反射。

## 边界与对比

白发、白布和白色硬件要通过轮廓及有限阴影区别。皮肤、内搭、绑带与护具之间有清楚边缘，避免环境渐变吞掉层次。
