# 配色与 2D 手绘语言

这一页说明颜色如何分工，以及线条、阴影和材质如何保持同一套 2D 手绘语言。面部身份参照<a href="/characters/bunny/face">面部基准</a>，服装与装备按下列规则分别核对。

## 本轮身体三视图的画风标准

采用**日系二次元手绘线稿与赛璐璐上色**。本轮基模、第一层白色上衣与红色短裤、袜装共九张完整人物已按此方向从空白画布重新绘制。新基模的[图面比例](/characters/bunny/dimensions)按对应新原图记录；[中性头部](/characters/bunny/face)与[16格表情](/characters/bunny/expressions)原件继续作为身份参考。三张既有结构板未在本轮重绘，鞋靴和后续装备尚未同步。

- **线稿清楚分层**：外轮廓完整，内部五官、衣物边缘和转折线更轻；线条保留自然粗细与收尖，不以模糊色边替代结构线。
- **固有色平涂**：皮肤、银白头发、蓝眼和黑色基础内衣保留各自清楚的主色面，不用连续明暗渐变填满形体。
- **阴影采用硬边色块**：以一层主要阴影交代朝向与遮挡；确有必要时增加少量深色遮挡块。边界明确，不保留柔刷、喷枪、雾状过渡或写实皮肤反光。
- **亮面克制且分区**：头发和衣物需要亮面时使用明确的小块色面，不沿身体轮廓铺塑料高光。皮肤保持干净，不通过光泽塑造体积。
- **保持身体比例**：保持已修订 v2 的头身关系、腰长、腿长、侧腰、胸臀轮廓、站姿与色系；不能为突出阴影而加粗肢体、收细腰部或另画一套形体。头部五官关系、共同视线与发束分组按本轮中性样板校准。

对照时先检查线条与色块边界，再核对三视轮廓是否保持一致。身体比例与画风的各自变化在[身体三视图](/characters/bunny/body-base)中对照。

## 完整三视的绘制方式

所有人物三视都从空白画布完整新绘，参考图只用于人物身份、比例、服装结构与配色的一致性。发现问题时整张重新绘制，不贴补身体或衣物，不局部修旧图，也不使用滤镜去除包浆。

逐张检查完整人物和原尺寸细节：耳部与发束连接、正侧背各自的身体结构、手足朝向和部件遮挡应成立；背面不能套用前胸锁骨式阴影。固有色与阴影保持连续、干净、边界明确，排除无设计依据的白斑、马赛克暗纹、灰雾揉擦与颗粒噪点。完整新绘后，图面尺寸必须对新原图重新量读，不能只更换来源标签沿用旧坐标。

## 配色分工

以下是从<a href="/characters/bunny/headgear#头部装备累计衣层">全身衣层</a>与独立部件中归纳的颜色用途，不是新增的精确色值标准。

<ul><li>橙色是主要服装识别面：外套和角色左腿长袜形成上下呼应，左腕设备与小型护盖作为局部点缀。</li><li>红色区分短裤、鞋靴主块、角色右腕护环和外套内襟；不要把红色内襟画成外套外表面的大块替色。</li><li>银白与白色提供明亮留白：头发、贴身上衣、角色右腿短袜，以及鞋靴上的白色拼片。当前头发以银白主面与少量冷灰蓝硬边阴影为准，不扩大为整片蓝紫色。</li><li>黑色建立结构边界：承载带、手套、袖口、领口与护目镜镜片。不要把这些不同部件连成一整块无边界的黑壳。</li><li>蓝色眼睛是面部的小面积识别点；肩部金色调节扣、银色挂扣只在各自固定位置提供金属点缀，不扩写成新的大面积配色。</li></ul>

## 线条与形体

<ul><li>外轮廓先保持完整、清晰，内部缝线、衣褶和织纹再分层加入；不能用密集纹理替代衣物形体。</li><li>头发按大块尖束分组，保留银白主面和冷色暗部；不把发丝画成均匀噪线。</li><li>宽袖由布量与转折形成体积，袖口收束、领口开合和口袋翻盖都要有明确边缘。外套体积不是身体变宽。</li><li>正、侧、背采用相同的部件边界与线条密度，不能某一视图突然转为写实渲染。</li></ul>

## 阴影与高光

阴影主要解释折面和遮挡：翻盖下方、领口内侧、袖口收束与内襟翻折，用边界明确的局部暗面建立前后关系。橙色衣身保持大块干净色面，不铺满渐变、颗粒或仿摄影反光。

金属扣件可以有克制的边缘亮面；针织和布面不沿整条外轮廓加塑料式高光。深色镜片与金属边缘的画法分别参照<a href="/characters/bunny/headgear#护目镜独立结构">护目镜独立结构</a>和<a href="/characters/bunny/harness#承载带扣件细节">承载带扣件细节</a>，不能把高反射效果复制到所有材料。

## 材质区分

<ul><li>针织：袜口用罗纹方向与轻微收束说明弹性；近景可画线圈与织物间隙，远景保留干净色块，不让织纹盖过腿部轮廓。</li><li>衣布：上衣、短裤与外套的结构通过包边、缝线、开口和布褶区分。参照<a href="/characters/bunny/innerwear#白色上衣结构">白色上衣</a>与<a href="/characters/bunny/innerwear#红色短裤结构">红色短裤</a>，不凭空增加材质花纹。</li><li>织带与扣件：黑色带面保持扁平、连续，金属钩环用边缘和开口区分。固定路径与金属反光是两件事，不用亮斑掩盖连接关系。</li><li>护目镜：深色镜片只保留小面积、受控的平面反光；嘴部和鼻尖保持外露，不增加面罩。</li></ul>

## 跨页复核

新增动作或视角时，先核对色块归属和部件边界，再检查阴影是否解释真实的遮挡。参考<a href="/characters/bunny/assembled">当前累计穿戴</a>确认整体，参考对应部件页确认局部；五官位置、蓝色瞳色与发束保持<a href="/characters/bunny/face">当前面部基准</a>。
