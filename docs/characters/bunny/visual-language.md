# 配色与 2D 手绘语言

这一页说明颜色如何分工，以及线条、阴影和材质如何保持同一套 2D 手绘语言。面部身份参照<a href="/characters/bunny/face">面部基准</a>，服装与装备按下列规则分别核对。

## 配色分工

以下是从<a href="/characters/bunny/headgear#头部装备累计衣层">全身衣层</a>与独立部件中归纳的颜色用途，不是新增的精确色值标准。

<ul><li>橙色是主要服装识别面：外套和角色左腿长袜形成上下呼应，左腕设备与小型护盖作为局部点缀。</li><li>红色区分短裤、鞋靴主块、角色右腕护环和外套内襟；不要把红色内襟画成外套外表面的大块替色。</li><li>银白与白色提供明亮留白：头发、贴身上衣、角色右腿短袜，以及鞋靴上的白色拼片。头发暗部偏冷灰紫，不涂成黑发。</li><li>黑色建立结构边界：承载带、手套、袖口、领口与护目镜镜片。不要把这些不同部件连成一整块无边界的黑壳。</li><li>蓝色眼睛是面部的小面积识别点；肩部金色调节扣、银色挂扣只在各自固定位置提供金属点缀，不扩写成新的大面积配色。</li></ul>

## 线条与形体

<ul><li>外轮廓先保持完整、清晰，内部缝线、衣褶和织纹再分层加入；不能用密集纹理替代衣物形体。</li><li>头发按大块尖束分组，保留银白主面和冷色暗部；不把发丝画成均匀噪线。</li><li>宽袖由布量与转折形成体积，袖口收束、领口开合和口袋翻盖都要有明确边缘。外套体积不是身体变宽。</li><li>正、侧、背采用相同的部件边界与线条密度，不能某一视图突然转为写实渲染。</li></ul>

## 阴影与高光

阴影主要解释折面和遮挡：翻盖下方、领口内侧、袖口收束与内襟翻折，用清楚的局部暗面建立前后关系。橙色衣身保持大块干净色面，不铺满渐变、颗粒或仿摄影反光。

金属扣件可以有克制的边缘亮面；针织和布面不沿整条外轮廓加塑料式高光。深色镜片与金属边缘的画法分别参照<a href="/characters/bunny/headgear#护目镜独立结构">护目镜独立结构</a>和<a href="/characters/bunny/harness#承载带扣件细节">承载带扣件细节</a>，不能把高反射效果复制到所有材料。

## 材质区分

<ul><li>针织：袜口用罗纹方向与轻微收束说明弹性；近景可画线圈与织物间隙，远景保留干净色块，不让织纹盖过腿部轮廓。</li><li>衣布：上衣、短裤与外套的结构通过包边、缝线、开口和布褶区分。参照<a href="/characters/bunny/innerwear#白色上衣结构">白色上衣</a>与<a href="/characters/bunny/innerwear#红色短裤结构">红色短裤</a>，不凭空增加材质花纹。</li><li>织带与扣件：黑色带面保持扁平、连续，金属钩环用边缘和开口区分。固定路径与金属反光是两件事，不用亮斑掩盖连接关系。</li><li>护目镜：深色镜片只保留小面积、受控的平面反光；嘴部和鼻尖保持外露，不增加面罩。</li></ul>

## 跨页复核

新增动作或视角时，先核对色块归属和部件边界，再检查阴影是否解释真实的遮挡。参考<a href="/characters/bunny/assembled">当前累计穿戴</a>确认整体，参考对应部件页确认局部；五官位置、蓝色瞳色与发束保持<a href="/characters/bunny/face">当前面部基准</a>。
