# 画风与配色 {.bunny-sr-only}
<span id="配色与-2d-手绘语言"></span>

这一页说明颜色如何分工，以及线条、阴影和材质如何保持同一套 2D 手绘语言。面部身份参照[面部基准](/characters/bunny/#identity)，服装与装备按下列规则分别核对。

## 画风标准 {#画风标准}
<span id="本轮身体三视图的画风标准"></span>

采用**日系二次元手绘线稿与赛璐璐上色**。身体与第 1–6 层（上衣与短裤、袜装、鞋靴、手部、腿带、橙色夹克）人物三视的图面比例按对应的身体原图记录。夹克采用前长后短轮廓，衣摆关系按[服装尺寸规范](/characters/bunny/dimensions#garment-dimensions)核对，保持平涂固有色与硬边阴影。银白发、蓝色眼睛、发束结构与五官关系以[中性头部](/characters/bunny/#identity)为依据。[16 格表情](/characters/bunny/#expressions)的身份、耳部连接、银白发色、线条密度与赛璐璐画风均与中性头部一致。

- **线稿清楚分层**：外轮廓完整，内部五官、衣物边缘和转折线更轻；线条保持自然粗细与收尖，不以模糊色边替代结构线。
- **固有色平涂**：皮肤、银白头发、蓝眼和黑色基础内衣保持各自清楚的主色面，不用连续明暗渐变填满形体。
- **阴影采用硬边色块**：以一层主要阴影交代朝向与遮挡；确有必要时增加少量深色遮挡块。边界明确，不使用柔刷、喷枪、雾状过渡或写实皮肤反光。
- **亮面克制且分区**：头发和衣物需要亮面时使用明确的小块色面，不沿身体轮廓铺塑料高光。皮肤保持干净，不通过光泽塑造体积。
- **保持身体比例**：保持身体的头身关系、腰长、腿长、侧腰、胸臀轮廓、站姿与色系；不能为突出阴影而加粗肢体、收细腰部或另画一套形体。头部五官关系、共同视线与发束分组按中性头部样板校准。

对照时先检查线条与色块边界，再核对三视轮廓是否保持一致。身体比例与画风在[身体三视图](/characters/bunny/body-base)中对照。

## 完整三视的绘制方式

人物三视从空白画布完整绘制，参考图只用于人物身份、比例、服装结构与配色的一致性。发现问题时整张重新绘制，不贴补身体或衣物，不以局部修补替代完整绘制，也不使用滤镜去除包浆。

逐张检查完整人物和原尺寸细节：耳部与发束连接、正面、角色右侧面与背面各自的身体结构、手足朝向和部件遮挡应成立；背面不能套用前胸锁骨式阴影。固有色与阴影保持连续、干净、边界明确，排除无设计依据的白斑、马赛克暗纹、灰雾揉擦与颗粒噪点。图面尺寸必须对对应原图量读，不能只更换来源标签而沿用另一张图的坐标。

## 配色分工

以下是从<a href="/characters/bunny/headgear#headgear-wearing">全身衣层</a>与独立部件中归纳的颜色用途，不是新增的精确色值标准。

- 橙色是主要服装识别面：橙色夹克和角色左腿橙色过膝袜形成上下呼应，角色左腕设备与匕首柄尾小标作为局部点缀。
- 红色区分短裤、鞋靴主块、角色右腕护环和夹克内襟；不要把红色内襟画成夹克外表面的大块替色。
- 银白与白色提供明亮留白：头发、贴身上衣、角色右腿短袜，以及鞋靴上的白色拼片。发色以银白主面为主，少量冷灰蓝硬边阴影说明发束重叠，不扩大为整片蓝紫色。
- 黑色建立结构边界：裤腰皮带、手套、袖口、领口与护目镜镜片。不要把这些不同部件连成一整块无边界的黑壳。
- 蓝色眼睛是面部的小面积识别点；双匕首以墨黑与骨白形成对比，少量红橙点保持角色配色关联。

## 线条与形体

- 外轮廓先保持完整、清晰，内部缝线、衣褶和织纹再分层加入；不能用密集纹理替代衣物形体。
- 头发按大块尖束分组，保持银白主面和冷色暗部；不把发丝画成均匀噪线。发旋、刘海、脸侧外翻束与后颈长度保持同一套分组，不用密集碎线或大面积蓝紫渐变塑造头发。
- 双耳朝后，由鬓发自然遮住耳根，银白发束采用清楚线稿、连续平涂与硬边阴影。
- 正面双眼朝向共同的视线目标，保持轻微自然差异，不把一只眼机械镜像到另一侧。角色右侧面按转向收窄可见眼形，眉眼、鼻尖、嘴与下颏保持连贯关系。
- 宽袖由布量与转折形成体积，袖口收束、领口开合和口袋翻盖都要有明确边缘。夹克体积不是身体变宽。
- 正面、角色右侧面与背面采用相同的部件边界与线条密度，不能某一视图突然转为写实渲染。

## 阴影与高光

阴影主要解释折面和遮挡：翻盖下方、领口内侧、袖口收束与内襟翻折，用边界明确的局部暗面建立前后关系。橙色衣身保持大块干净色面，不铺满渐变、颗粒或仿摄影反光。

金属扣件可以有克制的边缘亮面；针织和布面不沿整条外轮廓加塑料式高光。深色镜片与金属边缘的画法分别参照<a href="/characters/bunny/headgear#headgear-goggles">护目镜分件结构</a>和<a href="/characters/bunny/hands#cuff-opening">腕部护环结构</a>，不能把高反射效果复制到所有材料。

夹克的领口、角色左袖功能袋、袖口与前贴边见[夹克细节](/characters/bunny/jacket#jacket-details)。领口为随前襟断开的普通黑色短罗纹领，纯白 OG 连环品牌图形只位于角色左袖功能袋袋身正面中央。

## 材质区分

- 针织：袜口用罗纹方向与轻微收束说明弹性；近景可画线圈与织物间隙，远景保持干净色块，不让织纹盖过腿部轮廓。袜口与针织结构见[袜装页](/characters/bunny/hosiery)。
- 衣布：上衣、短裤与夹克的结构通过包边、缝线、开口和布褶区分。参照<a href="/characters/bunny/innerwear#白色上衣结构">白色上衣</a>与<a href="/characters/bunny/innerwear#红色短裤结构">红色短裤</a>，不凭空增加材质花纹。
- 织带与扣件：黑色带面保持扁平、连续，金属钩环用边缘和开口区分。固定路径与金属反光是两件事，不用亮斑掩盖连接关系。
- 护目镜：深色镜片只使用小面积、受控的平面反光；嘴部和鼻尖保持外露，不增加面罩。

## 跨页复核

新增动作或视角时，先核对色块归属和部件边界，再检查阴影是否解释真实的遮挡。参考[完整穿戴与携行](/characters/bunny/weapon#carry)确认整体，参考对应部件页确认局部；五官位置、蓝色瞳色与发束保持[面部基准](/characters/bunny/#identity)。
