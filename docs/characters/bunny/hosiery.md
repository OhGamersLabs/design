# 袜装

::: info 袜装层 · 橙色长袜与白色短袜
当前穿着稿以[完整新绘的第一层白色上衣与红色短裤](/characters/bunny/innerwear#layer1-wearing)为设计参考，分别展示从空白画布完整新绘的正、侧、背三视。本页背面本轮完整重绘，正面、侧面与结构细节板沿用此前新绘稿。[鞋靴层](/characters/bunny/shoes)现有完整穿着三视及独立结构板，[手部层](/characters/bunny/hands)现有穿着三视及两张部件板，[腿部层](/characters/bunny/thigh-gear)现有穿着三视及两张部件板，[外套层](/characters/bunny/jacket)现有穿着三视与两张部件板，吊带系统已取消，后续[裤腰皮带](/characters/bunny/harness)与[头装累计人物](/characters/bunny/headgear#headgear-wearing)已采用无吊带方案；当前基模和图面尺寸仍作为设计依据。
:::

角色左腿为橙色长袜，右腿为白色短袜。袜口贴合身体并产生轻微压痕，织物与腿部轮廓连续。

## 袜装穿着三视

三张完整新绘人物分别展示、放大和下载，保留生图工具直接输出的 1024×1536 PNG。以干净线条和平涂硬边阴影核对袜口、袜筒和完整足部，不在旧人物上贴补袜装。

当前背面核对了高腰红裤的遮挡：基模两处短记号按固定的腰窝／骶区提示处理，衣物覆盖后不再外露，也不移到裤腰边缘；可见后中沟保持简洁自然。

本轮背面以同视角基模核对发色、线条与赛璐璐分面，完整重绘人物；既定袜装与衣物覆盖关系保持，正面、侧面和结构细节板沿用。
