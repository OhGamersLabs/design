# 袜装是柔性层，不是外骨骼

## 构成

人物左腿穿橙色长袜，右腿穿白色短袜；灰色前臂套为独立部件。各自的上下边缘和长度保持清楚。

## 连接

袜口与短裤之间、踝口与鞋之间保留一致的覆盖关系。长袜不通过新增吊带连接短裤。

## 绘制

用少量硬边色块表达贴合形体。膝与胫部仍是织物曲面，不画成突起的刚性装甲。
