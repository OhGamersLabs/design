# 袜装

::: info 袜装层 · 橙色长袜与白色短袜
在[当前第一层白色上衣与红色短裤](/characters/bunny/innerwear#layer1-wearing)之上添加袜装，提供正、侧、背完整穿着稿与匹配结构资料。鞋靴和后续装备尚未同步；当前基模和图面尺寸仍作为设计依据。
