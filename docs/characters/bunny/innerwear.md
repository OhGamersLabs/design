## 分件结构 {#construction}

### 白色上衣结构 {#白色上衣结构}

<AssetImage id="white-top-v2-layer1-construction-v1" group="layer-1" />

白色上衣的款式结构包括领口、缝线与开口。

上排为成衣正面、角色右侧面、背面视图，下排为**部件与成衣接合位置示意**。部分成衣画出已装部件用于位置对照；编号是位置索引，不表示缝制顺序，也不提供可直接裁剪的纸样。

| 编号 | 对应部件与位置 |
| --- | --- |
| 1 | 领筒与衣身领口的接合位置。 |
| 2 | 胸前椭圆开口的包边位置。 |
| 3 | 袖窿包边与衣身边缘的接合位置。 |
| 4 | 下摆收边带与衣身底边的接合位置。 |

### 红色短裤结构 {#红色短裤结构}

<AssetImage id="red-shorts-v2-layer1-construction-v2" group="layer-1" />

红色短裤的款式结构包括腰头、开口和口袋。

上排为成衣正面、角色右侧面、背面视图，下排为**部件与成衣接合位置示意**。已装部件与分离部件可同时出现，用于对照位置关系，不代表完整爆炸拆分或裁剪纸样。

| 编号 | 对应部件与位置 |
| --- | --- |
| 1 | 腰头、前扣与门襟的接合位置；成衣画出已装腰头作对照。 |
| 2 | 前插袋的袋口包边与内部袋布。 |
| 3 | 后侧拼接片、中后腰带袢与后贴袋的位置。 |
| 4 | 裤脚翻边与裤身下缘的接合位置。 |

白色上衣与红色短裤的固定图面尺寸见[服装尺寸规范](/characters/bunny/dimensions#garment-dimensions)：衣长、裤腰截宽、裆部投影与裤脚分别标定，后续衣层沿用同一标准。
