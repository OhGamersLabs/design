# 贴身衣层

白色上衣与红色短裤已同步到 [v2 身体三视基准](/characters/bunny/body-base)，保留头部、手脚、腰腿比例与纤细轮廓。上衣的立领、袖窿、胸前椭圆开口，以及短裤的门襟、口袋和裤脚在三视中对应。

本轮只同步这一层衣服。袜靴、手腿装备、外套、承载带、头部装备与尺寸资料尚未同步。

## v2 · 贴身衣层三视

衣物采用平涂主色与硬边阴影，身体和头部沿用已完成的基准。侧视的前景手臂与手保持在衣物之前，衣物边缘按遮挡关系衔接。
