# 贴身层建立清晰的上下边界

## 版型

白色高领短上衣保留小型横向开口，背面使用简洁后中结构。红色短裤以明确裤腰和完整裤片收束，裤脚平直。

## 覆盖

正、侧、背对应同一裤腰高度与裤脚长度；白色上衣与皮肤之间的边界要明确，不能因高光混为一体。

## 材质

使用低对比平涂和少量折线表示织物。缝线服务于版型，不为增加复杂度而到处添加。
