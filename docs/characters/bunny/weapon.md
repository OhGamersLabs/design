# 双匕首 {.bunny-sr-only}
<span id="刺客双匕首"></span>

## 武器设计 {#design}
<span id="assassin-daggers-concept"></span>

<AssetImage id="daggers-scale-board-latest" group="weapon" caption="双匕首尺寸母版 · 并列正面外观" />

Bunny 以刺客定位使用两把各具完整造型的匕首：角色右侧是墨黑獠牙刃，宽阔的多面刃身配银色内凹刃缘，弯向钩形尖端；角色左侧是骨白弯刃，长弯刀形，刀根较直，向前端弯曲并收成掠起的尖端。每把刀身的红色仅为护手上方、刀背侧的一条细楔形色块。刃形、护手、握柄与柄尾分别设计，通过红领、橙色柄尾标记和共同的手绘赛璐璐画风保持成对关系。

整长设计目标为**角色右墨黑约 0.225 H0、角色左骨白约 0.263 H0**，H0 取身体基准发冠至赤脚地面。刀刃长度与握柄长度分别约束；各段长、正面宽度和测量定义见[双匕首尺寸规范](/characters/bunny/dimensions#weapon-dimensions)。

母版固定两把的正面轮廓和细分比例：骨白刀更长，握柄长度接近；刀身、护手与柄尾分别保持异构特征。母版不含窄侧视，厚度未测定。

两把各自按刀身、护手、红领、握柄和柄尾分为五个外观件。下方分件图把部件分别展示，小部件可能放大；整件与各段尺寸以正面母版和尺寸规范为准。

### 独立外观分件 {#dagger-components}

#### 墨黑匕首

<AssetImage id="daggers-dark-board-latest" group="weapon" caption="墨黑匕首 · 独立外观分件" />

墨黑獠牙刃宽阔多面，配银色内凹刃缘，刃缘弯向钩形尖端；刀身只有护手上方刀背侧的一条细红楔。非对称黑护手、单独红领、硬分段握柄与带橙色细标的多面柄尾分别展示。

#### 骨白匕首

<AssetImage id="daggers-ivory-board-latest" group="weapon" caption="骨白匕首 · 独立外观分件" />

骨白弯刃的刀根较直，向前端弯曲并收成掠起的尖端；刀身只有护手上方刀背侧的一条细红楔。月牙护手、单独红领、带浅色嵌条的流线黑柄和橙点水滴柄尾各自分开。

两张图说明可见外观，不定义内部装配或制造结构。

背面图中整刀弦长约为墨黑 0.228 H0、骨白 0.259 H0。计入端点取点与身体配准容差后，范围分别约为 0.219–0.237 H0、0.249–0.269 H0，两把总长设计目标均在对应范围内；读数依据见[携行背面图面核对](/characters/bunny/dimensions#dagger-figure-observations)。正面、侧面与 T 姿各视图不推断整刀长度。

正面里两处柄尾从腰侧露出：墨黑柄尾在角色右腰后（画面左），骨白柄尾在角色左腰后（画面右）；画面左侧胯旁还可见骨白刀尖；背面显示挂片与扣带的可见关系。

角色右侧面里，袖子后缘后方露出黑色柄部块面、红领与一颗银色圆扣，上方可见骨白柄尾尖及橙标。柄部下方沿臀后露出一段浅色窄刃投影。袖子和柄部相互遮挡，挂片与扣带的完整边界无法可靠分辨；不据此补齐整刀长度或侧厚。

墨黑匕首在角色右侧、骨白匕首在角色左侧；背面图里墨黑柄尾在画面右边、骨白柄尾在画面左边，正面图里相反。T 姿正面露出两处柄尾及画面左侧骨白刀尖，背面可见两把裸刃、挂片和按扣带，骨白在外浅 X 交叉。T 姿角色右侧面可见墨黑柄尾橙标、黑握柄与固定带；角色左侧面可见骨白柄尾橙标、黑白握柄、固定带与红领，两侧下方均露出叠合的窄刃投影。

角色右手对应墨黑獠牙匕首，角色左手对应骨白曲匕首；正面图中角色右手位于画面左侧，角色左手位于画面右侧。SUN-05 中两手同为正握。

携行图按母版与独立分件保持两刀各自的刀身、护手、握柄和柄尾形制，属于概念近似。动作与姿势投影不改写母版、身体和服装尺寸，也不作为严格工程正投影或由单张恢复物体真长的依据。

### 背后裤腰皮带挂片挂法 {#dagger-waist-mount-structure}

<AssetImage id="daggers-mount-board-latest" group="weapon" caption="背后裤腰皮带挂片挂法 · 单幅后腰近景，骨白刀在外交叉" />

图面可见：两把匕首不带鞘，挂在背后的裤腰皮带上。后中裤袢两侧各有一片黑色皮挂片；每把握柄各绕一条黑短带，各有一颗圆形银按扣，红领可见。裸露刀身浅交叉成 X，骨白在外。墨黑匕首在角色右侧，柄尾朝角色右上方；骨白匕首在角色左侧，柄尾朝角色左上方。

28° 设计目标取刀尖至柄尾端点连线相对水平的角度，柄尾朝上、朝外。握柄方向另行读取，比这条整刀弦更陡；握柄角度是图面观察值。

设计要求（图中未画出刀身穿过挂片的窄口与抽刀）：挂片上沿翻过皮带，在皮带下沿缝死；窄口与刀身垂直，长度正好等于刀身宽度；刀身从正面穿过窄口，到挂片后面贴着短裤，全部露在外面；护手卡在窄口，刀的重量压在护手上；按扣带压住刀柄根部，防止跑跳时刀向上脱出；取刀时先打开按扣，再沿握柄方向向外上方抽出。

人物背面图中，刀尖至柄尾的整刀弦相对水平约为墨黑 26.89°、骨白 28.93°（端点各坐标约 ±4 px，对应 26.02°–27.77°／28.16°–29.71°），相对 28° 分别偏低约 1.11°、偏高约 0.93°。柄尾橙标中心至红领中心的握柄方向另读为墨黑约 34.8°、骨白约 42.5°（两端中心各坐标约 ±3 px，对应 31.8°–37.9°／39.6°–45.5°），均比整刀弦更陡。黑色皮挂片顶边约与黑色皮带上沿齐平、局部略高，局部刀根被挂片遮挡，没有可独立辨认的穿刀窄口。两把刀尖均可见；端点、局部刀身轴角及身体配准见[携行背面图面核对](/characters/bunny/dimensions#dagger-figure-observations)。

这张挂法图是一幅后腰近景，没有编号分格或尺寸印字。图面可见关系如下：

| 部位 | 图面可见关系 |
| --- | --- |
| 黑色皮挂片 | 后中裤袢两侧各一片；挂片圆角顶端略高于黑色皮带上沿。上沿翻过皮带并缝在皮带下沿为设计要求。 |
| 握柄短带 | 每把握柄各绕一条黑短带，各有一颗圆形银按扣；红领仍可见。 |
| 护手与刀身 | 护手与黑挂片下缘重叠，裸露刀身向对侧延伸；没有可独立辨认的穿刀窄口，不能据重叠关系确认刀身进入挂片背面，也未画出皮带下沿的固定缝线。 |
| 交叉次序 | 背面画面右侧为墨黑柄，画面左侧为骨白柄；骨白刀身从墨黑刀身外侧跨过。 |

挂片上沿翻过皮带并在皮带下沿缝死、刀身穿过窄口到挂片后面贴着短裤、护手卡在窄口承重，以及按扣带压住刀柄根部，均为设计要求。挂法板未画出可独立辨认的穿刀窄口、挂片背面、皮带下沿固定缝线、开扣、空挂片或抽刀。

这张板用于说明挂片外观，不是武器本体分件图或尺寸基准。双刀轮廓与比例以[正面母版](#design)和[尺寸表](/characters/bunny/dimensions#weapon-dimensions)为准；人物三视说明携行状态。物理承载、抽取动作、动态间隙与 3D 碰撞未验证。

挂法参考仅作外链研究：[Klein Tools 5456TS 锤子挂架](https://www.kleintools.com/catalog/tool-organizer-accessories/hammer-holder-2-position-strap)用承托部件支撑工具、按扣带防止向上脱出，每个部件各负其责；[冲绳双钗的腰后交叉携带](https://www.usadojo.com/history-of-the-sai/)提供柄朝上朝外、背后皮带下浅 X 交叉的方向参考。Bunny 的黑色皮挂片与窄口形制是本设计的选择。
