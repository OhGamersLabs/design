# 三套部件组成一个头部系统

## 识别

B 型深色连片镜覆盖眼部，中央 U 形缺口避开鼻梁，鼻口与下巴露出。白色眉梁上保留三枚橙色夹扣。

## 连接

窄黑色耳机弧梁带细白边和橙色调节件；橙白耳杯与白色分节侧接清楚分层。兔耳根部的配饰安装保持独立。

## 绘制

头顶是白发，不是一体硬帽。发束以白色块和浅紫硬边阴影表达；镜体和耳杯用少量清晰高光，避免连续写实反射。
