# 腿部袜装与护具

## 袜装与前臂套

<ReleaseImage
  src="/characters/bunny/1.0.0/hosiery.webp"
  alt="袜装与前臂套"
  original="/media/bunny/1.0.0/hosiery.png"
  caption="袜装与前臂套"
/>

橙色长袜、白色短袜与灰色前臂套是三种不同部件。

长袜的曲面用少量硬边色块表达，不能在膝或胫部生成没有依据的硬质护板。

袜口、踝口与手套接合处需要合理重叠。转身后保持相同侧别与长度，避免正背互换。

这里的形体来自人体表面和织物贴合，不是关节机械外骨骼。

## 腿侧双带与盒袋

<ReleaseImage
  src="/characters/bunny/1.0.0/thigh-gear.webp"
  alt="腿侧双带与盒袋"
  original="/media/bunny/1.0.0/thigh-gear.png"
  caption="腿侧双带与盒袋"
/>

双带环绕人物右大腿，外侧盒体与软袋分开绘制。正面视图里它位于画面左侧。

带子的前、侧、后要相连，扣具不能随着镜头转动换到另一条腿。

设计分析：两道带可以限制旋转，但仅凭图不能证明跑动时不滑落。

后续动作测试应关注屈髋、蹲下与外套下摆是否碰到盒袋。

## 护膝与膝后红带

<ReleaseImage
  src="/characters/bunny/1.0.0/knee-guard.webp"
  alt="护膝与红带"
  original="/media/bunny/1.0.0/knee-guard.png"
  caption="护膝与红带"
/>

黑色护膝居于膝前，红色固定带绕到膝后。后视图必须出现带面，而不是把它缩成一条袜褶。

护片与上方服装保持间距，不形成跨过整个膝关节的刚性长板。

运动检查应区分硬片、带子和袜面：屈膝时需要软层与带路容许变形。

本书不把中性站姿的合理性写成全动作无穿模证明。
