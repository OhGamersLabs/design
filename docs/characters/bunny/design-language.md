# 设计语言与色彩材质

## 形象语言

白发与白色兔耳形成轻亮上部轮廓，黑色护目镜压住视觉重心；橙外套与单侧橙袜产生上下呼应。红色短裤和鞋提供次级色块，避免全身被一种橙色吞没。

## 部件逻辑

柔性衣物贴合或覆盖身体，绑带负责固定与附挂，硬质护具保留独立边缘。正面说明识别与层次，背面说明装备走向，局部拆解说明连接。

## 配色角色

- 橙色：外套、长袜与连接件。
- 红色：短裤与鞋的主要色块。
- 白色：头发、兔耳、内搭与硬件。
- 深灰黑：护目镜、领口、绑带与鞘。
- 淡紫灰：白发和白色部件的阴影。

最终色彩关系应参考同一张角色卡，避免单独调亮某个部件而破坏整体。

## 手绘 2D 画法

头发用大束不透明白色块、明确轮廓和少量淡紫硬边阴影，不堆细丝与连续柔光。布料用折线解释褶皱与张力，暗部克制；橙袜与外套仍应读成织物。硬件用少量清晰高光面表达硬度，避免真实金属反射、塑料油亮感或 3D 产品渲染。
