# 工具外观与收纳关系成套设计

## 工具构成

机壳、握把、导板与链条各自可辨；链齿沿封闭导向连续排列。

## 收纳

鞘覆盖导板与链条，机体与手柄留在人物右肩上方，长鞘斜向左髋。鞘口与工具体量相互对应。

## 背负

肩带和腰部连接表达携行关系并释放双手。抽取路径、真实重心与运动摆动须独立验证。
