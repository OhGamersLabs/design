第 0 层严格锚定通用 [标准青年男素体（1.08×）](/standards/male-standard) 的颈下骨架、左右肩宽、地平线与哑光炭黑平角短裤基准，将头部确立为五十二岁白塔守夜院长索伦·韦恩的温厚长辈骨相，确保第 1 至第 3 层朴素常服在同一比例人台上严丝合缝叠穿。厘米身高未设定。

- **五十二岁温厚学者骨相**：温和舒展的眉弓、微垂沉静的石板蓝双眸与眼尾慈和笑纹，摒弃一切脸谱化尖锐冷酷线条；第 0 至第 2 层统一采取裸脸无眼镜状态，完整交代柔和眉眼与法令纹转折。
- **七三偏分霜灰层叠短发**：发丝呈自然柔和的霜灰夹暖灰褐光泽，彻底摒弃炸刺背头；发缝位于角色左侧（正面图位于画面右边），发流自然梳向角色右侧与耳后，后颈发梢干净贴合衣领线上方。
