第 0 层严格锚定通用 [标准青年男素体（1.08×）](/standards/male-standard) 的颈下骨架、左右肩宽、地平线与哑光炭黑平角短裤基准，将头部确立为五十二岁白塔最高执印官索伦·韦恩的冷峻骨相，确保第 1 至第 3 层礼装在同一比例人台上严丝合缝叠穿。厘米身高未设定。

- **五十二岁冷峻贵族骨相**：高挺鼻梁、利落颧骨与下颌折角，眉心与眼尾带成熟内敛的威严细纹；双眸为冰冷锐利的铂金浅琥珀瞳色；第 0 至第 2 层统一采取裸脸无眼镜状态，完整展示眉弓与眼眶转折。
- **铂银夹深炭背梳短发**：发丝整体向后背梳，鬓角与后颈底层透出深炭灰底发，顶层覆高明度铂银白发束；发缝微偏角色左侧，前额固定垂落两缕纤细银白碎发轻搭于角色右眉上方（正面图位于画面左边，角色右侧面清晰可见），后颈发尾干净收束于衣领线上方。
