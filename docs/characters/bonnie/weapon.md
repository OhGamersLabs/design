# 双匕首 {.bunny-sr-only}
<span id="刺客双匕首"></span>

## 武器设计 {#design}
<span id="assassin-daggers-concept"></span>

<AssetImage id="daggers-scale-board-latest" group="weapon" caption="双匕首尺寸母版 · 并列正面外观" />

Bunny 以刺客定位使用渡月工业风的异构双匕首：角色右侧是墨黑微链刃，多面哑光炭黑刃身沿外曲缘排布连续银色微链节，根部嵌入橙色驱动开关、双竖向细槽与紧固螺钉；角色左侧是骨白高频弯刃，修长陶瓷白配银色掠曲刃缘，刀身带机加工分缝线、两道修长深色开槽，以及近根部的一条细斜红标。两把均采用紧凑不对称小护手、单独红领、直段八角握柄（墨黑柄为全炭黑八角，骨白柄为带竖向白色嵌条的哑光黑八角）及带单枚橙色圆点的切面柄尾，通过共同材质语言与赛璐璐画风形成成对关系。

整长设计目标为**角色右墨黑约 0.225 H0、角色左骨白约 0.263 H0**，H0 取身体基准发冠至赤脚地面。刀刃长度与握柄长度分别约束；各段长、正面宽度和测量定义见[双匕首尺寸规范](/characters/bonnie/dimensions#weapon-dimensions)。

母版固定两把的正面轮廓、细分比例以及微链驱动与开放式紧凑握柄局部；骨白刀更长，握柄长度接近。母版不含窄侧视，厚度未测定。

两把各自按刀身、护手、红领、握柄和柄尾分为五个外观件。下方分件图把部件分别展示，小部件可能放大；整件与各段尺寸以正面母版和尺寸规范为准。

### 独立外观分件 {#dagger-components}

#### 墨黑微链刃
<span id="墨黑匕首"></span>

<AssetImage id="daggers-dark-board-latest" group="weapon" caption="墨黑微链刃 · 独立外观分件" />

墨黑微链刃为多面哑光炭黑刃身，沿外侧弯缘排布连续银色金属微链节，根部可见橙色三纹驱动开关、两道竖向细槽与两颗银色螺钉。紧凑不对称黑护手、单独红领、直段八角炭黑握柄与带单枚橙色圆点的切面柄尾分别展示。

#### 骨白高频弯刃
<span id="骨白匕首"></span>

<AssetImage id="daggers-ivory-board-latest" group="weapon" caption="骨白高频弯刃 · 独立外观分件" />

骨白高频弯刃的刀根较直、向前端修长掠曲，表面带机加工分缝线、两道深色开槽与根部斜向细红标。紧凑白银不对称护手、单独红领、带竖向双白嵌条的直段八角黑柄和带橙色圆点的黑切面柄尾各自分开。

两张图说明可见外观，不定义内部装配或制造结构。

背面图中整刀弦长约为墨黑 0.237 H0、骨白 0.260 H0。计入端点取点与身体配准容差后，范围分别约为 0.227–0.246 H0、0.250–0.270 H0；读数依据见[携行背面图面核对](/characters/bonnie/dimensions#dagger-figure-observations)。正面、角色右侧面与 T 姿各视图不推断整刀长度。

正面里两处带橙点的八角柄尾从腰侧露出：墨黑柄尾在角色右腰后（画面左），带竖向白嵌条的骨白柄尾在角色左腰后（画面右）；画面左侧胯旁还可见修长骨白刀尖；背面显示挂片与扣带的可见关系。

角色右侧面里，袖子后缘后方露出黑色八角握柄、红领、黑皮固定带与一颗银色圆扣，上方可见橙点柄尾。柄部下方沿臀后露出一段陶瓷白窄刃投影。袖子和柄部相互遮挡，挂片与扣带的完整边界无法可靠分辨；不据此补齐整刀长度或侧厚。

墨黑微链刃在角色右侧、骨白高频弯刃在角色左侧；背面图里墨黑柄尾在画面右边、骨白柄尾在画面左边，正面图里相反。T 姿正面露出两处橙点八角柄尾及画面左侧骨白刀尖，背面可见两把裸刃、挂片和按扣带，骨白在外浅 X 交叉。T 姿角色右侧面可见墨黑柄尾橙点、炭黑八角握柄、银扣固定带与红领；角色左侧面可见骨白柄尾橙点、带白嵌条黑八角握柄与红领，两侧下方均露出叠合的窄刃投影。

角色右手对应墨黑微链刃，角色左手对应骨白高频弯刃；正面图中角色右手位于画面左侧，角色左手位于画面右侧。SUN-05 中两手同为正握。

携行图按母版与独立分件保持两刀各自的刀身、护手、握柄和柄尾形制，属于概念近似。动作与姿势投影不改写母版、身体和服装尺寸，也不作为严格工程正投影或由单张恢复物体真长的依据。

### 背后裤腰皮带挂片挂法 {#dagger-waist-mount-structure}

<AssetImage id="daggers-mount-board-latest" group="weapon" caption="背后裤腰皮带挂片挂法 · 单幅后腰近景，骨白刀在外交叉" />

图面可见：两把匕首不带鞘，挂在背后的裤腰皮带上。后中裤袢两侧各有一片黑色皮挂片；每把握柄各绕一条黑短带，各有一颗圆形银按扣，红领可见。裸露刀身浅交叉成 X，骨白高频弯刃在外。墨黑微链刃在角色右侧，柄尾朝角色右上方；骨白高频弯刃在角色左侧，柄尾朝角色左上方。

28° 设计目标取刀尖至柄尾端点连线相对水平的角度，柄尾朝上、朝外。握柄方向另行读取，比这条整刀弦更陡；握柄角度是图面观察值。

设计要求（图中未画出刀身穿过挂片的窄口与抽刀）：挂片上沿翻过皮带，在皮带下沿缝死；窄口与刀身垂直，长度正好等于刀身宽度；刀身从正面穿过窄口，到挂片后面贴着短裤，全部露在外面；护手卡在窄口，刀的重量压在护手上；按扣带压住刀柄根部，防止跑跳时刀向上脱出；取刀时先打开按扣，再沿握柄方向向外上方抽出。

人物背面图中，刀尖至柄尾的整刀弦相对水平约为墨黑 30.66°、骨白 30.06°（端点各坐标约 ±4 px，对应 29.80°–31.52°／29.29°–30.84°），相对 28° 分别偏高约 2.66°、2.06°。柄尾橙标中心至红领中心的握柄方向另读为墨黑约 33.4°、骨白约 36.4°（两端中心各坐标约 ±3 px，对应 29.9°–37.1°／33.0°–39.8°），均比整刀弦更陡。黑色皮挂片顶边约与黑色皮带上沿齐平、局部略高，局部刀根被挂片遮挡，没有可独立辨认的穿刀窄口。两把刀尖均可见；端点、局部刀身轴角及身体配准见[携行背面图面核对](/characters/bonnie/dimensions#dagger-figure-observations)。

这张挂法图是一幅后腰近景，没有编号分格或尺寸印字。图面可见关系如下：

| 部位 | 图面可见关系 |
| --- | --- |
| 黑色皮挂片 | 后中裤袢两侧各一片；挂片圆角顶端略高于黑色皮带上沿。上沿翻过皮带并缝在皮带下沿为设计要求。 |
| 握柄短带 | 每把握柄各绕一条黑短带，各有一颗圆形银按扣；红领仍可见。 |
| 护手与刀身 | 护手与黑挂片下缘重叠，裸露刀身向对侧延伸；没有可独立辨认的穿刀窄口，不能据重叠关系确认刀身进入挂片背面，也未画出皮带下沿的固定缝线。 |
| 交叉次序 | 背面画面右侧为墨黑柄，画面左侧为骨白柄；骨白刀身从墨黑刀身外侧跨过。 |

挂片上沿翻过皮带并在皮带下沿缝死、刀身穿过窄口到挂片后面贴着短裤、护手卡在窄口承重，以及按扣带压住刀柄根部，均为设计要求。挂法板未画出可独立辨认的穿刀窄口、挂片背面、皮带下沿固定缝线、开扣、空挂片或抽刀。

这张板用于说明挂片外观，不是武器本体分件图或尺寸基准。双刀轮廓与比例以[正面母版](#design)和[尺寸表](/characters/bonnie/dimensions#weapon-dimensions)为准；人物三视说明携行状态。物理承载、抽取动作、动态间隙与 3D 碰撞未验证。

挂法参考仅作外链研究：[Klein Tools 5456TS 锤子挂架](https://www.kleintools.com/catalog/tool-organizer-accessories/hammer-holder-2-position-strap)用承托部件支撑工具、按扣带防止向上脱出，每个部件各负其责；[冲绳双钗的腰后交叉携带](https://www.usadojo.com/history-of-the-sai/)提供柄朝上朝外、背后皮带下浅 X 交叉的方向参考。Bunny 的黑色皮挂片与窄口形制是本设计的选择。
