头部只有护目镜。护目镜采用白色切面哑光外框、窄条深烟灰镜片、橙色多切面侧扣与半埋式细黑弹性镜带，默认抬至额头佩戴，露出眼睛、鼻子和嘴部。

细黑镜带从两端橙色侧扣各向后斜伸一小段，随即收进耳上方的外层银白发束之下，背面视角仅呈现连贯洁净的银白碎发，不露出外露黑镜带或侧扣件。

穿着三视显示身体至护目镜的第 0 到 7 层：白色内搭、橙色夹克和护目镜，不含裤腰皮带。

人物比例参照[身体尺寸](/characters/bonnie/dimensions#body-dimensions)。

## 细节 {#details}

<span id="headgear-closeup"></span>

<AssetImage id="goggles-closeup-board-latest" group="layer-7" caption="额头佩戴七格细节板 · 半埋镜带、背面纯发、侧扣与标注" />

护目镜抬在额头上，双眼、鼻子与嘴部外露。黑镜带从橙色切面侧扣斜向后微伸即潜入银白外发层之下，背面仅见纯净银白碎发，后脑环绕路径以顶视黑虚线示意；本板没有眼前佩戴状态。

| 图中标记 | 中文说明 |
| --- | --- |
| 01 FRONT | 正面：白色切面外框与烟灰镜片置于额头，两端橙色侧扣与短露后收进发丝的黑镜带相接。 |
| 02 RIGHT SIDE | 角色右侧面：橙色切面侧扣位于耳前上方，黑镜带斜向后下收进耳上发丝之中，发后段全被发束遮覆。 |
| 03 BACK | 背面：洁净连贯的银白碎发，没有外露黑镜带、橙侧扣或后脑扣。 |
| 04 GOGGLES ALONE | 护目镜单件：白色切面外框、深烟灰镜片和角色左侧与角色右侧的橙色切面侧扣的正面外观。 |
| 05 SIDE CLIP | 侧扣特写：多切面橙色扣件、炭黑底框、白色外框端与细黑弹性带的扣槽连接。 |
| 06 TOP | 俯视：前方护目镜体与绕过头顶后方的虚线，示意发丝下方环绕头围的隐蔽镜带路径。 |
| 07 DIMENSIONS | 位置与带宽的板面印字标注：HEAD TOP 0%（发冠 0%）、CLIP CENTRE 38%（侧扣中心 38%）、STRAP AT BACK 58%（发下隐蔽镜带后位 58%）、CHIN 100%（下颏底尖 100%）；SLOPE 18 DEG（镜带斜度 18°）、STRAP 5%（镜带宽 5%）。 |

第 07 格的百分比与 18° 均为板面印字标注，未登记为设计目标；CHIN 100% 引导线对齐下颏底尖，虚线示意被外层发丝遮覆的镜带走向，侧扣不是翻转铰链，不能按绘图反推这些数值。
