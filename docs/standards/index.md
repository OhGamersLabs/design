## 画风与调用 {#rules}

<p>全家族人型角色统一调用四档素体作为第 0 层基础人台，避免单角色另起骨架与画风漂移。</p>
</div>

<div class="base-body-rules-grid">
  <div class="base-body-rule-card">
    <h3>统一画风与线重</h3>
    <p>全套采用日系 TV 动画赛璐璐平涂风格：近黑粗实外轮廓配利落细内线，单一硬边阴影，画面左上方主光，纯白底无投影无标尺，四档同框时肤色与线稿观感完全统一。</p>
  </div>
  <div class="base-body-rule-card">
    <h3>通用占位头设计</h3>
    <p>四档均配深炭黑短发与中性深灰瞳的平静占位头，不带任何头饰、护目镜或装饰，耳廓、下颌线、颈部与斜方肌完整露出，便于创建具体角色时整头替换。</p>
  </div>
  <div class="base-body-rule-card">
    <h3>第 0 层换头与分层换装</h3>
    <p>新角色制作第 0 层身体时，直接取对应档位同角度七张视图作为母版，仅替换头部与发型（可按设定微调肤色），锁定颈下体型、站姿与画幅；进入衣层后直接覆盖人台打底或平角短裤逐层穿戴。</p>
  </div>
  <div class="base-body-rule-card">
    <h3>T 姿多视建模规范</h3>
    <p>每档 T 姿四视均为 1024×1024 纯白底正交图，涵盖正面、角色右侧面、背面与角色左侧面。角色左侧面与角色右侧面均省去近侧手臂，完整露出圆润肩帽、胸背起伏与腰臀侧轮廓。</p>
  </div>
</div>
